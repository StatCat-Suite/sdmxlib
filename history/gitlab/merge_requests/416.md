The remaining scope of #364 — and far smaller than that issue predicted, because
!415's conformance work had already closed most of it.

## One bug stood between the two versions

A Level's `codingFormat` carried `decimals` and `isMultiLingual`. It constrains
*codes*, exactly as an `enumerationFormat` does, and `gaps.py` has declared that
loss since #159 — but only the XML writers ever honoured it. SDMX-JSON 2.0
leaves objects open and tolerated the extra keys; 2.1 closes them and rejects
the document.

Fixing it takes our output from three 2.1 errors to **zero**. The three were one
cause cascading — the innermost failure left the enclosing `level` and
`hierarchies[0]` unevaluated, which made it read as a Hierarchy-shaped problem
until I stripped the two keys by hand and watched all three disappear.

## Reading 2.1 already worked

The official SDMX-TWG 2.1 sample parses with no 2.1-specific code — all eight
sections. The reader keys on section names, and those did not change between
versions. What 2.1 changed is that it *closes* every object, so the whole burden
was on the writer.

## So what "2.1 support" is

One writer and one reader, with output held to **both** schemas.
`_JSON_SCHEMAS` validates the census against 2.0 and 2.1 on every run — which is
what keeps it true, since the bug that broke it validated perfectly well under
2.0 alone. A test reads the official 2.1 sample for the other direction.

`meta.schema` stays absent deliberately: 2.1 makes it optional and the
standard's own sample omits it.

## A control replaced rather than deleted

`test_coding_format_facet_loss_is_real_and_recorded` proved the CodingFormat gap
was real by showing the facet dropped in XML and **kept** in JSON — a control
that stops working the moment JSON honours the restriction too. The permitted
facets (maxLength, minLength, pattern) take that job over, so `decimals is None`
still cannot pass by the whole facet having vanished. That test exists because a
previous control showed the entry could be deleted with the suite staying green;
worth not re-introducing the same weakness while fixing it.

`just ci` green: 5827 unit / 53 docs / 86 integration. Planting the bug back
fails the new check.

Closes #364.

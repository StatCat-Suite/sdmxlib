A backend that computes nothing answers by fetching artefacts and running the original query over them, so the fetch must close over every relation the query's paths reach. Fetch one short and nothing fails — the query evaluates against an empty table and returns nothing.

## Containment is not a crossing

    ()                                          0  none
    ('dataflow',)                               0  none         <- extension: one artefact, two tables
    ('dataflow','dsd')                          1  children
    ('dataflow','dsd','dimensions')             1  children     <- containment: arrives with the DSD
    ('dataflow','dsd','dimensions','concept')   2  descendants

The first cut keyed on "does this hop land on the spine". Wrong: `component.concept` lands on the `concept` table, not `artefact`, and is still a crossing. What decides it is whether the key being followed is the *target's* identity or the source artefact's — so a reverse hop is containment, and a forward hop crosses unless it is the `artefact.urn -> dataflow.urn` identity.

## The rule is pinned to the wire

`test_the_depth_rule_matches_what_the_wire_returns` fetches one level short **on purpose** and asserts that zero concept ids resolve. That silent wrong answer is what the module exists to prevent, so it is asserted rather than described. Read from cassettes; no network.

`references=all` is never produced — §11 measured 29.8 MB for one codelist.

## Two clauses writing it down found

- **`qualify`.** `rank().over(q.dataflow.dsd.agency)` names no filter and no sort key, so a closure built from predicates and order keys alone fetches nothing for it and ranks every row against a null partition — one answer, quietly wrong. `WinPred` is a separate hierarchy from `Pred` by design, so `shapes_of` does not accept one and it needs its own walk.
- **`cursor`** needs no branch after all: it carries values and directions, not columns, and the columns it positions against are the order keys already covered. Recorded in a comment rather than left looking like an omission.

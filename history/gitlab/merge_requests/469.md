## The six that were real

* **`serving(data=)`** in `tests/docs/pages/_offline.py` declared `bytes | None`
  while forwarding to `_data_stubs`, which takes a per-flow
  `Mapping[str, bytes]`. A page passing the mapping was correct; the signature
  said otherwise.
* **`_EXR_DIMENSIONS`** was inferred with `Unknown` elements, because its tuples
  differ in length. Every lookup keyed on one degraded — which is how
  `name={"en": _EXR_LABELS.get(...)}` came out as `dict[str, str | None]`.
* **Four bench modules** imported `artefact_urn` from `in_memory_registry`,
  which only re-imports it. It is defined in `model.ref`.
* **`test_compete.py`** reached `pysdmx.io.format` and `pysdmx.io.writer` with
  plain imports after an `importorskip` on the *parent* package, so a partial
  install raised at collection instead of skipping. Both now go through
  `importorskip` as well.
* **`Source.version`** is `SchemaVersion`, not `str` — it feeds
  `compile_structure_schema`, and every value already was one.
* **`test_bundle_reads`** read `pstats.Stats.total_calls`, which `Stats` assigns
  in `init()` rather than declaring, so typeshed carries no such attribute.
  Summing `profiler.getstats()` is equal by construction (verified against
  `total_calls` directly) and is fully typed — no suppression needed.

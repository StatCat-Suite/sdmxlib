## Data sources: not a writer bug

The reader reads queryable and simple data sources on a data constraint, because SDMX-JSON 2.0 allows them. The writer refuses them, and that is correct. SDMX-JSON 2.1 dropped them, and sdmxlib's `"json"` output must validate against both 2.0 and 2.1. An earlier draft of this MR called the refusal a bug; it was not, and the doc and tests now say why.

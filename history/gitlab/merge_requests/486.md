A guard for this already existed. `tests/unit/test_suite_is_relocatable.py`
(#252) scans for working-directory-relative reads and points at
`tests.support.repo.ROOT`, which walks *past* mutmut's `mutants/` copy to the
real checkout. It has been there since #252 and it caught nothing in #284 or
#324, because both were a different spelling:

```python
Path(__file__).parents[2] / "tools" / "count_any.py"
```

That is not working-directory-relative. It is anchored — and still wrong, since
under mutmut `__file__` is inside `mutants/tests/unit/` and two levels up is
`mutants/`. The scan looked for relative literals and said nothing about it.

**Four occurrences now**, three of them found only when someone next tried to
run mutation: #265 (fixed in #252), #284, and #324's second instance, which was
the worst — it failed in the *stats* phase and printed
`1610 mutants  killed 0  survived 0`, a full-looking summary with every number
at zero rather than an abort.

## What this does

* **Anchors all eleven sites** to `repo.ROOT` — the three `tools/` importers,
  the `docs/cookbook` reader, and seven more the new scan turned up that nobody
  had looked at (`tests/docs/*`, `test_ml3_fork_drift`, `test_registry_naming`,
  `test_query_order`, `test_sql_ast_invariants`).
* **Removes the three skip guards** that stood in for the fix. A test that
  skips itself in the mutation tree is a test mutation cannot use, which is the
  same hole one level quieter.
* **Extends the #252 guard** with `_file_anchored_escapes`, so both spellings
  are enforced by the file that already owns the rule. They are one rule —
  *anchor to `ROOT`* — that was being enforced over half its surface.

Verified the only way that means anything: the full unit suite run *inside* a
freshly built `mutants/` tree. **6,539 passed, 0 failed.**

## `also_copy` is the wrong fix, and the repo says so itself

mutmut does have the setting, and `also_copy = ["docs", "tools"]` genuinely
puts them in the tree — I tried it first. But `find_root` distinguishes the
checkout from the copy by looking for a directory holding **both**
`pyproject.toml` and `docs/`, so copying `docs/` makes `mutants/` satisfy the
marker pair and `ROOT` starts resolving to the copy.
`test_the_root_helper_finds_the_checkout_not_the_mutants_copy` failed within a
minute of the attempt, which is the guard doing exactly its job. Recorded in
the module docstring so the next person does not spend the same hour.

Closes #402.

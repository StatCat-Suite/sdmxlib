Step 5c of #516, the final step: **observation data has one surface.** `reg.observations(flow) -> ObsQuery` now does everything `Dataset` did (!678–!682), and `reg.scan_csv` / `reg.scan_json` read a file into the same query (!683, !684). So the second surface goes.

**Removed (breaking):**
- `RestRegistry.data()` and its key-building helpers (`_KeySpec`, `_DataflowSpec`, `_serialise_key`, `_key_slots`, `_validate_key_spec`, `_make_spec_resolver`, `_run_fetch`, `_fetch_data`). `_to_references` moved into `api/registry.py`, since structure fetches still use it.
- `sdmxlib.api.query` (`DataQuery`) and `sdmxlib.api.filters` (`sl.dim`, `DimFilter`).
- `sdmxlib.model.dataset` (`Dataset`), along with `sl.Dataset` and `sl.model.Dataset`.
- `sdmxlib.polars.scan_csv` and `write_data_json`, and `formats.sdmx_csv.reader.scan_csv`. The reader keeps the structure-resolution helpers that `scan_csv` uses.
- `read_sdmx_json_data` in both versions. `read_observations` remains.
- `SdmxClient.get_data` / `stream_data_to`, which only served `reg.data()`. `download_data` and the path-based `*_data_at` methods stay.

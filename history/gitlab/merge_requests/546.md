Part of #422. Three constructs the read-side register reported lost are now modelled; the register is down to **links on identifiable artefacts** and **N:M component maps**, in both SDMX-ML and SDMX-JSON.

## Decisions (agreed)

- **Annotation URLs:** `Annotation.url` → `urls: tuple[AnnotationURL, ...]`, `sl.AnnotationURL(url, lang=None)` — the wire shape, repeats and all; a bare string is accepted.
- **Query:** `q.annotation.url` → a `q.annotation.urls` fan-out (`url`, `lang`, `position`) over a new `annotation_url` side table, declared as an edge like every other side table; plus a `q.annotation_url` root.
- **Sentinels:** `Facet.sentinel_values: tuple[SentinelValue, ...]`, `sl.SentinelValue(value, name, description)`.

## Formats

- Empty `AnnotationURL` elements are no URL (Eurostat ships ~830k).
- **Validation** refuses a sentinel on an `enumeration_format` or a level's `coding_format` (`CodedTextFormatType` / `CodingTextFormatType` have none; `Facet` serves all three).
- gaps.py: `annotations[].urls` on the same twenty annotation sites as `AnnotationValue` (walker shared, `_reach`); `sentinel_values` on the seven representation sites; `time_range.valid_*` on regions.

## Storage — schema 2.32

- `annotation_url (annotation_id, position, url, lang)`; `annotation.url` dropped. Read with a `list(...)` subquery per annotation rather than a second LEFT JOIN (which would multiply the text rows) — no extra statements. Cascade deletes it (a codelist re-write: 11 `DELETE`s; the loose `<= 10` bound in `test_cascade_dispatch` is now `<= 12`, with the count written down).
- `sentinel_values` as a typed list-of-struct column on `concept`, `dsd_component`, `metadata_attribute` — last in each, as an in-place `ADD COLUMN` puts it. **Typed explicitly on write:** pyarrow inferred the nested MAPs as structs keyed by the first row's languages, so an empty description read back as `{en: None}` (caught by the store census).
- `region_selection.time_valid_from / time_valid_to`.
- Bundle migrated (dry run first; `annotation.url` held 0 URLs). DuckDB refuses `DROP COLUMN` while indexes depend on the table, so the four `idx_ann_*` were dropped and recreated around it. `.2.31.bak` kept until merge.

## One subtlety the writer half did not have

`read_constraints` uses `c` **both** as a comprehension variable and as the namespace helper, 34 lines apart:

```python
c for c in (structures.find(s("DataConstraints")), …)   # comprehension target
...
region_el.findall(c("KeyValue"))                        # the helper
```

A per-function exclusion would have broken the helper calls; a naive rewrite would have broken the comprehension. The transform tracks comprehension scopes — their own scope in Python 3 — and qualifies only genuine closure references. Verified both survived correctly before applying.

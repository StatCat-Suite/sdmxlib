## Decisions (asked)

- **Map id:** a map read from a 2.1 `StructureSet` is named `<map>@<set>`, so `CLM_FREQ` in `SS_A` becomes `CLM_FREQ@SS_A`. A map keeps its bare id inside the set our writer invents, which carries the existing annotation marker. The rule now lives in `model/_container.py` (`member_id` / `inner_id`), shared with hierarchies.
- **StructureSet → 3.x / SDMX-JSON:** the maps are written and the set is left out, as a declared `sdmx_class` gap that `dropped()` names. This was a whole-message refusal.
- **Map validity and external reference:**
  - **On read:** each map takes its set's validity and external-reference attributes.
  - **On write:** maps that no declared set claims go into invented sets split by those attributes as well as by agency and version (`SS_SYNTHETIC`, `SS_SYNTHETIC_2`, …), so a standalone map's attributes come back.
  - **Refused:** a 2.1 write refuses a member of a declared set that disagrees with the set, by the same check as for hierarchies, now `_check_containers_in_21`.
  - **gaps.py:** the twelve 2.1 rows declaring these fields lost on maps are gone.

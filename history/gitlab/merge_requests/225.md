## `match=` assertions — 85, one genuine problem

Against 89 bare `pytest.raises`. **Exactly one** asserts on third-party text, and I wrote it in !208:

```python
match=r"\$\.data\.codelists\[0\]\.id"
```

The `$.`/`[0]` syntax is **msgspec's**, not our contract — a version bump could reword it. It now asserts on the field names, which are ours:

```python
assert "codelists" in message   # locates the section
assert "id" in message          # names the field
```

Still discriminating, which was the thing to check before loosening: the pre-#200 message read ``at `$[0].id``` with **no mention of `codelists`**, because each section was converted in isolation. So the assertion still catches a regression to per-section conversion.

The other 84 assert on sdmxlib's own messages — `Invalid SDMX URN`, `Ambiguous`, `expects a SdmxUrn`. Contract, not detail.

## `KNOWN_GAPS` — where the audit earned itself

Of three entries, **one was dead**. `("storage", "hierarchy", "level.coding_format")` never applied, because `hierarchy` was absent from `_STORAGE_PUT` and `_storage_params` skips any case not listed there — so no test was generated at all.

**A strict xfail that generates no test is invisible.** It does not fail when the gap closes, nor when it widens. It had been sitting there claiming to document something nothing checked.

Adding `hierarchy` to `_STORAGE_PUT` did two things: confirmed the documented gap is **still real** (it xfails), and exposed a second, undocumented one — which turned out to be a live bug.

## The bug: eager hierarchy reads dropped `has_formal_levels`

```
put_hierarchy(conn, h)          with has_formal_levels=True
get_artefact(..., eager=True)   -> False      <- silently wrong
get_artefact(..., eager=False)  -> True
```

`_read_hierarchy` never read `hierarchy_meta`, so every **eager** read returned `False` regardless of what was stored. The lazy path read it correctly, so the two read paths disagreed about the same row — no error, no warning.

Fixed, and the round-trip guard now covers it, so it cannot regress silently again.

`just ci` green — 2845 unit, 72 docs, 56 integration; xfails 2 → 3, which is the previously-dead gap now doing its job.

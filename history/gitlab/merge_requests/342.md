# Merge request !342: fix(query): a column whose type nothing states, and two window bugs (#328)

| | |
| --- | --- |
| State | merged |
| Opened | 2026-08-17 |
| Merged | 2026-08-17 |

Range filters, `is_in` and shares did not compile over observations,
because ordering and arithmetic live on `Num` and a dataflow's column
cannot claim a type. #328 proposed moving them to `Col`. That would have
been wrong.

**`Version` is why.** It extends `Str` and overrides only `sort_column`,
so an inherited text `>=` would make `version >= "1.10"` **true** for
`1.9` — #311 as a predicate rather than as an ORDER BY. Today that
mistake is unspellable, and widening the base would make it spellable
everywhere in order to fix it in one place.

So `Untyped` is a column class that opts in. It offers only what means
one thing without a declared type — comparison and ordering, `is_in`
without `Str`'s member check, `-`/`*`//`, and `.str` where the caller
states the reading — and the structural surface is untouched.

**`+` is absent, deliberately.** It is addition on `Num` and
concatenation on `Str`, and with nothing to pick by, inheriting `Str`'s
would compile `a + b` to `||` and silently concatenate two measures into
`"12"`.

Enabling the share turned up **a structural bug that had shipped**:
a windowed operand inside a computed expression rendered as its own
source column, so `depth / depth.sum().over(codelist)` compiled to
`(s0.depth / s0.depth)` — valid SQL, wrong answer, no error. Every share
was 1. Fixing the render then exposed the second half: a window's
partition columns are collected for a *top-level* window and not for one
nested in an expression, so the corrected render died on
`KeyError: ('codelist',)`. Both fixed, with the regression tests in
`test_query_windows.py` because that is where the bug lived.

The expression-surface guard demanded a sample of the new class and got
one, built through the observations root rather than constructed — the
binding is the accessor there. And the observations test that asserted
range filters were impossible now asserts they work, which is what it was
written to do.

## Summary

Extends \`tests/bench/test_compete.py\` with SDMX-JSON 2.1 serialize timing. Counterpart to the existing SDMX-ML serialize comparisons from MR !84.

\`sdmx1\` has no SDMX-JSON writer at all so the comparison is sdmxlib vs pysdmx only. \`pysdmx\`'s SDMX-JSON 2.1 writer crashes (\`ValueError: substring not found\`) on the ECB DSD fixture — their bug; we skip that case for pysdmx and bench sdmxlib alone.

## What this tells us

- **sdmxlib JSON serialize is ~17% slower** than pysdmx on 3.8 MB. The conformance work in MR !95 added per-emit overhead (name/names split, named arrays per scheme, MappedValueType wrappers, format/dataType rename, etc.) — that cost is real but bounded.
- **sdmxlib output is ~23% smaller** than pysdmx (compact: 987 KB vs 1.28 MB) so per-byte throughput is closer than wall-time suggests.
- **sdmxlib is fully conformant** to the SDMX-JSON 2.1 schema (MR !95 wired in the validator across all 8 SDMX-ML 3.0 fixtures).
- **sdmxlib handles fixtures pysdmx can't.** The ECB DSD crashes pysdmx's JSON writer; sdmxlib serialises it in 1.9 ms.

a 6.36 s eager codelist read**, and for a `Code` it was guaranteed to find

## What was happening

Three walkers rediscover the same structure at runtime, per object:

| walker | what it does with the refs |
| --- | --- |
| `local.registry._collect_refs` | batches unresolved ones for resolution |
| `model.in_memory_registry._walk_refs` | interns them |
| `model.validation._collect_refs` | records their paths for error messages |

That structure is a property of the *class*. `model/_refshape.py` computes it
once and caches it, so a `Code` is skipped before a single field is read.

## The assumption, and what bounds it

#376 asked for this to be stated rather than buried: reading **declared types**
treats a declaration as a guarantee about a runtime value.

- **Conservative where it cannot see** — `object`, `Any`, an unresolved string
  annotation, a bare `TypeVar`, a container with no element type all answer
  "maybe". An unreadable annotation costs speed, never correctness.
- **Differentially checked**, in the sense the query oracles use: the old
  value-based walk is *restated* as an oracle rather than imported, so a change
  to the implementation cannot move the oracle with it. Asserted one-way (the
  static answer may be wider, never narrower) over every attrs class discovered
  in `sdmxlib.model` and over a graph parsed from twelve reader fixtures —
  parsed, not hand-built, because a hand-built graph contains the fields its
  author remembered.

## Two findings from mutation-checking the module

Six mutants, all now caught. Two survived at first, and neither was simply a
missing test:

- **A dead arm that read as load-bearing.** `_is_container` in `walk_fields`
  decided nothing: `_classes_in` already yields `None` for a bare container and
  the element type for a parameterised one. Removed.
- **The cycle set could be deleted with everything green.** `HierarchicalCode`
  has the self-referential shape, but its `code: Ref` field returns True before
  the closure ever recurses — so the model is a bad witness for its own cycle
  guard. `_SelfRef` in the test file is a witness that bites, and it has to be
  **module-level with resolved annotations**: a class defined inside a test
  function has unresolved string annotations, reads as "unreadable", answers
  True immediately and recurses nowhere. The first version did exactly that and
  asserted nothing.

## Notes for review

- **`validation._collect_refs` is deliberately untouched.** Its descent is
  hand-listed and covers two artefact types (#148's own comment); generalising
  it changes which refs validation reports, and that is a behaviour change, not
  a perf one. It is where #148 picks up.
- **The `Any` ratchet goes 38 → 39**, reason recorded in
  `tools/any_baseline.txt`. `_is_opaque` compares an annotation *against*
  `typing.Any` so the module can be conservative about it — the opposite of
  using it, and load-bearing: `Any` passes `isinstance(x, type)` on 3.11+, so
  without the comparison it reads as an ordinary class and the field is
  skipped. That is the one way this module could be unsafe rather than slow.
- **A `walked`-set behaviour change**, called out in the docstring: a class
  that cannot reach a `Ref` is no longer added to it. Marking would cost a set
  entry per object to short-circuit a call that already returns immediately.
  The `_resolve_refs` frontier still terminates — a re-visited object
  contributes nothing to `pending`, and the next frontier is built from
  `pending`.

## Two defects in the #380 property, found on the way

Both in the test, not the library, and both worth naming:

- It built its MAP literal with Python `repr`. `repr("'")` is `"'"`, which
  DuckDB reads as an **identifier** — so it raised a binder error on a value
  the library handles correctly. CLAUDE.md's *never interpolate values into
  SQL* applies to tests that build SQL too; the map is now bound.
- At 20x width it then drew a lone surrogate `\ud800`, which is not valid UTF-8
  and cannot exist in a column at all. That tested the driver's error handling
  rather than this transport, so the strategy excludes `Cs`, with the reason
  written down.

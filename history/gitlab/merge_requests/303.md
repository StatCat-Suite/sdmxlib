Closes #280.

`q.component` exposed **6 of `dsd_component`'s 25 columns**. Getting the other
19 meant answering the design question the issue left open — *are the
representation facets fields, or a nested accessor?* — and looking at the
storage to answer it turned up why they had been left out.

## The layout was the real finding

`Representation` is one IM concept, and the schema wrote it out **three times**
(`concept`, `dsd_component`, `metadata_attribute`). The copies had drifted
twice:

| | `concept` | `dsd_component` | `metadata_attribute` |
| --- | --- | --- | --- |
| naming | `repr_*` prefixed | bare | bare |
| `is_multilingual` | ✓ | ✓ | **absent** |

The second is **live data loss**: a `MetadataAttribute` carrying a multilingual
facet round-tripped as `None` while a `Concept` and a `Dimension` kept it —
silent, and invisible to 4,882 passing tests, because every facet fixture in
the suite left that one field unset.

Neither drift was visible from any single table, which is the argument for
deriving the group rather than repeating it. The DDL now interpolates one
`_FACET_COLUMNS` fragment into all three tables, `FACET_COLUMN_NAMES` is
parsed from that fragment rather than restated beside it, and three guards
hold it — the tables agree with **each other**, the name list matches the DDL,
and no table carries a `repr_` prefix again.

## The accessor needed no new machinery

A facet is a **zero-hop accessor**: it binds the empty path, so its columns
resolve against the owner's own row exactly as a flat column would. No join,
nothing for the planner to do. The two arms of
`Representation = Ref[Codelist] | Facet | None` now read symmetrically:

```python
q.component.codelist.id == "CL_GEO"     # enumerated — a real edge
q.component.facet.max_length > 100      # free text — a namespace
q.concept.facet.text_type               # same spelling, any owner
q.metadata_attribute.facet.pattern
```

The eleven fields are declared once in `_FACET_FIELDS` and built per owner by
`__init_subclass__` — deriving rather than enumerating, the same lesson as the
DDL.

**Unreachable columns: 19 → 1.** The survivor is `repr_kind`, derivable from
either arm being non-null.

## Test gates from the issue

- **Differential properties** against the in-memory DSD — the oracle the issue
  asked for, and a *shipped* code path, so it cannot drift to match what it
  checks. Six properties; verified to discriminate (mutants making
  `max_length` read `min_length` and `role` read `component_id` are both
  caught). Its limit is written down too: both sides share the writer, which
  is exactly how the `is_multilingual` loss survived, and the schema guard is
  the mitigation.
- **Cookbook**: `discovery.md` gains "Components as rows" and "Representation:
  the two arms", with 11 driver tests — including one asserting the
  catalogue-wide frame really is one statement, which the frame alone cannot
  distinguish from a resolution loop.

## Two things found on the way

**A wire break.** `is_multi_lingual` is a naive camelCase split of the spec's
`isMultiLingual`; English writes it as one word. Renaming it silently
re-derived the SDMX-JSON wire name as `isMultilingual`, because
`_camel_rename` derives names from Python identifiers — the old spelling was
correct *by accident*. Nothing failed: msgspec calls the renamer once at class
definition, `omit_defaults` drops the field when unset, and no fixture set it.
Now an explicit override beside `agencyID`, guarded in both directions.

**A guard that assumed every sub-accessor is an edge.** Rather than exempt the
zero-hop case, its branch asserts the thing that matters: a namespace's
`__table__` must equal its owner's, or it resolves columns against a table the
query never joined. Mutation-checked.

## Breaking

- `Facet.is_multi_lingual` → `Facet.is_multilingual`. The SDMX-ML and
  SDMX-JSON wire attribute `isMultiLingual` is unchanged.
- Stored facet columns are unprefixed on every table, so a `concept` row's
  `repr_max_length` is now `max_length`. `SCHEMA_VERSION` 2.5 → 2.6; the store
  is a cache and rebuilds.

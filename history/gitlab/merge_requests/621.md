## A measurement fault, fixed first

mutmut credits a function to the tests that are running when it is hit. `gaps.py` builds its 289-row register from small predicate factories, which run while the module imports, during collection and before any test. Every one of those hits went to whichever test ran first. Each factory mutant was then run against a single test about annotation URLs, so it survived.

The first `_any_node_has` mutant is an example. It survived the full run, yet a fresh `test_field_coverage` run kills it immediately.

`tools/mutmut_forksafe.py` now takes collection-time hits out before the first test starts. It credits each one to every test that reaches its module at run time. The readers and writers build their tables the same way, so this had to come before their baselines.

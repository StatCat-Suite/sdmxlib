Closes #208. First application of CLAUDE.md rule 4 — package-internal APIs get a plain name in a private module.

## Half the premise did not survive reading the sites

#208 listed six places reaching into `Ref._resolved`. **Only three are writes.** The other three were *reads* where a public property already existed:

```python
if ref._resolved is not None:      ->  if ref.resolved:
if value._resolved is None:        ->  if not value.resolved:
interned._resolved = ref._resolved ->  if ref.resolved and not interned.resolved:
                                           intern_resolution(interned, ref())
```

So three sites were never a missing-API problem — they were code not using the API it already had. Worth noting because the issue (mine) framed all six as evidence that `Ref`'s write side was missing; only half of that was true.

## The seam

`model/_interning.py` — private by **module path**, plain function name:

```python
def intern_resolution[T](ref: Ref[T], obj: T) -> None:
    ref._resolved = obj
```

Why not a method on `Ref`: a public `ref.resolve(obj)` would advertise, on every Ref a user holds, exactly the call that de-canonicalises the graph — and `__all__` cannot prevent it, since it governs module-level names, not attributes of an exported class. Verified both directions:

```
intern_resolution in sdmxlib.__all__   -> False
sdmxlib.intern_resolution reachable    -> False
importable by path (intended)          -> True
```

`in_memory_registry.py` and `local/registry.py` no longer touch `_resolved` directly.

## No suppression, which is the point

#208 anticipated the seam would carry one `# noqa: SLF001` in place of six. !199 retired SLF001, so the write is ordinary code and the seam carries **zero**. That leaves its value purely as API design — naming the boundary rather than silencing a lint, which is what the issue argued was the real benefit.

## Tests

* **resolution propagates to a Ref taken *before* the artefact was added** — the invariant the seam exists to protect. Verified non-vacuous: `False` before, `True` after, and the same object identity.
* the seam is absent from the public API

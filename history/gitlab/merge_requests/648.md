## Refused writes are labelled as refusals

`just bench-compete` writes with `validate=False`, so it times the writer alone. It then called a file the default `serialize` refuses `INVALID`. BIS's `_T` parents in SDMX-ML 3.0 read as an sdmxlib bug, though #432 already refuses that case.

## Scale tier

Each read is labelled the same way, so equal-content rows are marked rather than assumed. UNSD and ECB are English only with no parents, and pysdmx `keeps everything counted` there. On those rows:
- sdmxlib reads SDMX-ML faster (7.5 against 8.4 ms per 1k codes);
- writes are level;
- pysdmx reads SDMX-JSON 2.8× faster.

So the JSON gap is not about sdmxlib holding more. It is construction and checks, and %24 / #493 track that.

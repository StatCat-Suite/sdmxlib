## Census changes

- **Defaults.** `maxOccurs`, `minOccurs` and `usage` are counted with their value, like the booleans already were. The schema defaults join `DERIVABLE`, beside `@leveled=false`.
- **Empty elements.** An element with no text, no children and no attribute but `xml:lang` is counted under `path(empty)`, which is derivable. An element carrying an `id`, such as `<Annotation id="isFinal"/>`, still counts as content.

Two new tests, each pairing the quiet case with one it must catch:
- `maxOccurs="1"` dropped is derivable; `maxOccurs="25"` dropped is real.
- An empty `AnnotationURL` is derivable; an `<Annotation id>` is real. Sabotage-checked.

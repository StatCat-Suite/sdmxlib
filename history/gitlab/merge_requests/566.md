## Problem

`tools/generate_allowed_children.py` counted every particle a type declares. An `xs:restriction` that keeps a particle at `maxOccurs="0"` is forbidding it, not allowing it. SDMX 3.x's `MetadataAttributeUsageBaseType` does this for `ConceptIdentity` and `LocalRepresentation`, so a DSD's `<str:MetadataAttributeUsage>` carrying either one was read past silently.

## Change

- The generator skips `maxOccurs="0"` particles. Only four schema sites use it, the same two elements in 3.0 and 3.1.
- `_allowed_children.py` is regenerated. Such a document is now refused, with `<str:ConceptIdentity>: not allowed in <str:MetadataAttributeUsage>`.
- The element census's "prohibited" entries are removed, since those pairs are no longer allowed.
- New tests cover the table cases and refusal in both versions and children. I restored the old table to check that they fail: 6 failures.

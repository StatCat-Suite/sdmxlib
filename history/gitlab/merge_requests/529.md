`LocalRegistry.get(h.urn)` returns a `LazyHierarchy`. Its `materialize()` built each node without `annotations`, so every node came back with none, while `get(eager=True)` and the `q.hcode` collect kept them.

## Fix

One query per `materialize()`: `resolve.annotations_of_artefact`, keyed on `owner_artefact_urn`. That is the indexed column #145 added for the delete cascade. Registering the node URNs for `annotations_for_urns` would mean half a million of them on the FED hierarchy; this does one equality lookup instead.

## Guard

The store census (`test_store_round_trip.py`) read eagerly only, which is why it missed this. A second test now requires every lazy proxy `get()` returns to materialise to the eager artefact, field by field through the census.
- **Exact:** it asserts which slots return proxies (two codelists and a hierarchy), so a proxy that appears or disappears is seen.
- **Sabotage-checked:** dropping the node annotations again fails it on exactly `tree[0].annotations` and `tree[0].children[0].annotations`.

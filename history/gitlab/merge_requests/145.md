## What

Thread a `type[T]` **witness** through the shared ref-resolution helpers so the
format readers carry **real ref types** instead of `Ref[Any]`.

Before, readers parsed an untyped URN and dropped it into a typed field via
`AnyRef` (= `Ref[Any]`), so `Dimension.concept` & friends silently degraded to
`Ref[Any]` off the wire. Now each call site supplies the artefact class the
target field expects:

- `resolve_ref[T](el, index, cls: type[T]) -> Ref[T] | None` (ML `_common`)
- `_resolve_urn[T](urn_val, index, cls: type[T]) -> Ref[T] | None` (JSON)

The parse-`Any` lives and dies **inside** the helper; callers only ever see
`Ref[T]`. Readers now carry `Ref[Concept]`, `Ref[Codelist]`,
`Ref[DataStructure]`, `Ref[MetadataStructure]`, `Ref[Code]`, `Ref[Hierarchy]`.
Genuinely heterogeneous refs (metadata targets, categorisation / scheme-map
source·target, constraint attachments) pass `object` → `Ref[object]`, the honest
type.

`resolve_ref` is typed through a callback `Protocol` (`_ResolveRef`) because a
plain `Callable` annotation can't carry a free type parameter.

## Why not covariance (the original #173 spike)

#173 first spiked making `Ref[T]` **covariant**. Measured and rejected:

- `@frozen` can't infer covariance for an attrs class (fields model as
  settable), so covariance costs an **irreducible 5 casts in `ref.py`**.
- Its only benefit is a *checked* `Ref[object]` for the heterogeneous slots —
  which buys little on fields consumed generically (`.urn`, `str`, compare).
- The readers' problem was a **downcast** (untyped URN → typed field), which
  covariance can't fix. They needed **witnesses**, not variance.

`AnyRef = Ref[Any]` now survives only at genuinely-open edges, where `Any` is
the defensible choice (see `docs/design/json-and-parsing.md`).

## Impact

- ~52 reader call sites now typed; **zero casts / zero new `# type: ignore`**.
- **Removes** an existing `# type: ignore[assignment]` (JSON `linkedHierarchy`).
- New: `docs/design/phantom-generics.md` — why `parse(str) -> SdmxUrn[Any]` and
  the witness pattern that recovers the type at the typed slot.
- `just check` clean; **2405 unit tests pass** (runtime unaffected — annotations
  erase, witnesses are type-only).

Closes #173.

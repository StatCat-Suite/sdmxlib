Closes #204 — but not the way it was written.

## The premise didn't survive testing

#204 was scoped as **documentation**: record that 8 `Any` annotations are correct, so a fourth pass doesn't re-derive the same verdict. Before writing that down I checked it. **7 of the 8 were not justified.** They were simply untyped, and the Protocols describing them already existed:

```
obj / parent   -> agency_id, id, version    ==  SupportsUrn
item           -> id                        ==  SupportsId
artefact_type  -> sdmx_package, sdmx_class  ==  type[SupportsUrn]
```

| site | was | now |
| --- | --- | --- |
| `sdmx_json/reader.py` `_index_artefact` / `_index_item` | `Any` ×3 | `SupportsUrn` / `SupportsId` |
| `sdmx_ml/_common.py` `index_artefact` / `index_item` | `Any` ×3 | same |
| `sdmx_json/_resolve.py` `resolve_urn` | `Any` | `object` |
| `sdmx_json/_data_common.py` `display_names` local | `Any` | `Dataflow \| DataStructure` |

`resolve_urn` is the clearest: its body opens with `isinstance(urn_val, str)`, which narrows `object` perfectly well — the `Any` was never doing anything. That module is now `Any`-free. In `display_names`, dropping the `Any` also let a `getattr(src, "name", None)` dance collapse into a plain attribute read.

I'd been about to write "these are correct" into the codebase, which would have made the wrong verdict *harder* to revisit — a comment saying "deliberate" is exactly what stops the next person looking.

## What actually remains

**`src/` now has zero `Any`-annotated parameters or locals.**

The only `-> Any` left that is not an `AnyRef` or the documented `Ref.__getattr__` proxy is `readers.get_artefact`. That one is genuinely justified — it dispatches on the runtime `artefact_type` column via `_READERS`, so no static type describes the result, and narrowing to `object | None` would add an isinstance step at all **66** call sites without making anything safer. Documented in place, pointing at `Registry.get` as the typed entry point.

## Proposal: retire the ANN401 shell exemption (needs your call)

`ruff.toml` currently exempts `formats/`, `storage/` and `local/` from ANN401 — because those layers *had* `Any` parameters. They no longer do.

I tested this in a **throwaway config copy** (`ruff.toml` is protected and was not modified). Lifting the exemption from all three directories yields exactly one finding:

```
ANN401 Dynamically typed expressions (typing.Any) are disallowed in `get_artefact`
    --> src/sdmxlib/storage/readers.py:1560:6
Found 1 error.
```

So the three-directory exemption could be replaced by a **single scoped `# noqa: ANN401`** on `get_artefact` — turning ANN401 on everywhere and making this MR's result enforced rather than merely achieved. `Ref.__getattr__` already carries exactly that form, so the precedent exists.

Both halves need your approval under CLAUDE.md: editing `ruff.toml`, and adding a suppression. I've done neither. If you want it, it's a two-line change and I'd do it as a follow-up so this MR stays a pure code change.

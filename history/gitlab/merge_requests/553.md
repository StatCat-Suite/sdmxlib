The attribute twin of the element census (!547, !550). This is the first of the three MRs agreed: census and loss rows now; then the maintainable flags; then the concept and format fields.

## Census
- `tests/support/xsd_attributes.py` reads the attributes each element allows from the vendored XSDs. It follows extension and restriction (`use="prohibited"` honoured), `attributeGroup` and `ref=` (`xml:lang`), and keys elements by name as `_allowed_children` does.
- `tests/unit/test_attribute_census.py` compares, per version, the allowed `(element, @attribute)` pairs with those the writer emits for `maximal` and the version's shapes. Every unwritten pair is classified as one of:
  - **loss**: a `LOSSES` row exists;
  - **derived**: a URN;
  - **fixed**: the schema fixes it (a data key's `include`, an organisation scheme's 2.1 `isFinal`);
  - **alternative**: the HCL alias, read by a named test;
  - **absent**: two types share the element name.
- The test checks both directions, has a discrimination test, and checks a sample of the attributes the walker reads off the XSDs.

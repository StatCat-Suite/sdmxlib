Closes #352, and #353 on the way.

`edge()` took the target **class object**, evaluated in the class body, so
a target defined further down the file could not be named and the edge
fell back to `_Maintainable`. Seventeen did. Which ones was decided by
where 63 classes happened to sit in one 1584-line file:

    _Concept   is defined at 479, before _Component (640) -> typed
    _Codelist  is defined at 1020, after  _Component      -> truncated

    q.dsd.components.concept   -> _Concept
    q.dsd.components.codelist  -> _Maintainable

Same relation, one hop, opposite outcomes, and nothing about the domain
explains it. Worse, it made **file order part of the public API**:
reordering for readability would add or remove what users can express,
and no test could have said so.

`edge()` now takes the target's *name*, resolved on first read from the
declaring module via `__set_name__`. The annotation was always what the
checker read; only runtime needed deferring. Fifteen edges now name a
concrete accessor and five stay `_Maintainable` because they really are
polymorphic — `categorisation.artefact` can point at anything — which is
now a declared choice rather than a fallback indistinguishable from one.

Queries that were `AttributeError` and now run:

    q.dsd.components.codelist.codes.id == "A"
    q.code.codelist.agency
    q.concept.scheme.concepts.count() > 0
    q.hcode.hierarchy.hcodes.id
    q.metadata_attribute.msd.attributes.id

`test_query_edges` gains the durable half: a guard asserting no edge lands
on `_Maintainable` without being listed as polymorphic, and that no entry
in that list has since been given a concrete target. Without it the same
drift returns silently.

**`test_a_component_still_stops_at_the_maintainable_surface` asserted the
opposite and is now inverted.** Its reasoning was sound for the mechanism
it was written against — `_Dsd.components` needs `_ManyComponent` needs
`_Component` needs `_Dsd`, a mutual recursion no reordering resolves. A
named target dissolves it: `_Component` can say `"_Dsd"` before `_Dsd`
exists. So the limit was the mechanism's and not the domain's, which is
what that test said it wanted pinned so as not to be mistaken for.
Traversal terminates because a path only grows as far as a caller dots.

**#353, taken because it blocked the gate.** `just test-properties` failed
on main, and once the seed moved it began failing at default width too.
Both oracles restated `strip_accents` as `not unicodedata.combining(ch)`
— the canonical combining *class*, which is 0 for every spacing mark.
Measured over 8,025 characters: that predicate disagrees with DuckDB on
527, `category(ch)[0] != "M"` on none. Both fixed, plus
`test_oracle_fold.py` pinning each oracle to the function rather than to
a description of it — a fixed sweep finds in milliseconds what needed 20x
width and a Gujarati vowel sign to surface.

Note both oracles carried the same wrong line. Rule 1 keeps them from
sharing code; it cannot keep them from independently restating the same
wrong idea, which is the failure mode CLAUDE.md names as the one
differential testing cannot catch. Checking each against the database
rather than against each other is the mitigation.

The one `cast` is basedpyright's prescribed double hop through `object`,
on the line that builds the descriptor it describes — a factory returning
the value type is what every descriptor's does.

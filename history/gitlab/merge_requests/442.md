## The gap

Every aggregate over a to-many edge was unconditional:

```python
c = q.dsd.components
reg.query(q.dsd).select(ids=c.list(c.id))
# ['FREQ', 'GEO', 'OBS_STATUS', 'OBS_VALUE']

reg.query(q.dsd).filter(c.any(q.component.role == "Dimension")).select(ids=c.list(c.id))
# ['FREQ', 'GEO', 'OBS_STATUS', 'OBS_VALUE']    ← unchanged, and correctly so
```

`filter` chooses which *rows* come back, never which children are collected; rooting at the child gives the rows and loses the grouping. So "the dimensions of each DSD" had no spelling. Now:

```python
c.list(c.id, where=q.component.role == "Dimension")   # ['FREQ', 'GEO']
c.count(where=q.component.role == "Measure")          # 1
```

## Shape

A keyword, not a chained `.where(p)`. A filtered fan-out object would have duplicated what already exists — `fan.where(p).any()` **is** `fan.any(p)` — and predicates already go inside the operation in this language. Django spells it `Count(..., filter=Q(...))`; `where=` rather than `filter=` because `Query.filter()` means something else here.

Both spellings take it, and they differ in what the checker can hold them to:

| form | `where` type |
| --- | --- |
| `fan.list(cols, where=…)` | `Pred[C]` — wrong-relation predicate is a checker error |
| `fan.col.list(where=…)` | `AnyPred` — `Col[R]` carries the row projected *onto*, not the row restricted |

That asymmetry is why **`AnyPred` is now exported**: #299's rule is that every type in a public signature is importable, and the decision is recorded in `test_the_expression_types_stay_private` beside the same argument that exported `AggPred`.

## Three things worth a look

- **The restriction is part of an aggregate's identity.** `__canonical__` carries it, or `order_by` would match a filtered aggregate against an unfiltered one — the identity bug that method exists to prevent, one level in.
- **`_conjoin([])` is `TRUE`.** Folding an empty restriction in unconditionally added `AND TRUE` to the SQL of every existing aggregate. It is only built when there is one, and a test asserts the unfiltered text is unchanged.
- **Empty collects to `[]` / `0`, never NULL** — the rule an unrestricted aggregate already followed, pinned rather than described, because a correlated subquery with no rows is exactly where a NULL would appear.

## Coverage

Aggregates had **no** differential coverage — both query oracles model predicates. Three properties close that for the filtered forms: a list and a count compared against a direct walk over the `Code` objects (sharing nothing with the compiler but Python's own semantics), and a law — restricting never collects more than not restricting — that holds for every codelist including the ones the first two skip.

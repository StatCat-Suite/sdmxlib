Running a block proves it does not raise. It does not prove the page is
*right*: `print(cl.codes.ids())  # ["A", "Q", "M"]` runs identically when
the answer is `["A"]`, and that comment is what a reader acts on.

The runner now reads those comments back. No new syntax — the pages
already state 63 expected outputs this way, and the check is a
consequence of the documentation being accurate rather than a thing
authors maintain separately. 53 are verified; the other 10 are prose
(`# falls back to "Annual"`, `# 250+`) and are counted, because a
value/prose heuristic that fails open silently is a check that decays.

Output is captured by binding a recording `print` into the block's
namespace: the line number is what maps an output back to its claim, and
only the calling frame has it. That works inside a `for` or a `with`,
which statement-splitting would not.

Two page conventions are honoured rather than skipped. `...` means the
claim is a *prefix* — `# ["AE", "AR", "AU", ...]` is checked as one —
because abbreviating long output is deliberate and the longest outputs
are the most drift-prone. `value — why` is split, since half the pages
annotate their claims.

**It found three fixtures lying and two pages broken.** The BIS
reference-area codelist was a clone of the geography one, so
`# ["AE", "AR", "AU", ...]` was false; `data.md` served one union DSD to
three providers, so `print(ds.dimensions)` reported nine where the page
says ECB EXR has six; and `data.md` used `REF_AREA`/`INDICATOR` on an ECB
dataset that has neither, which a reader following the page top-to-bottom
would hit as a `KeyError`. `serving` now takes a payload per dataflow id,
so each provider answers for itself.

**And the second copies are gone.** Ten hand-written drivers, ~3,300
lines, each saying "every code example must work" — which is now the
runner's job, from the page rather than from a copy of it. Deleting them
lost four behaviours that only they reached, so those moved to unit tests
where library contracts belong: `Frame.order_by` refusing a dropped
column, `LazyHierarchy`'s `include_self`, `LocalRegistry.check_binding_
drift`, and `from_dict` rebuilding a `time_dimension`. Coverage went
*up* — 877 missed to 858 — because the targeted tests reach more than the
drivers did.

`test_upgrading.py` stays: it asserts removed names are *absent*, which
no executable block can.

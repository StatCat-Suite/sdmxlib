## Writer bugs fixed

| # | Bug | Symptom |
|---|---|---|
| 1 | \`codelistExtensions\` never emitted | Model carried them; JSON silently dropped on round-trip |
| 2 | \`concept.core_representation\` never emitted | XML readers/writers handled it; JSON didn't |
| 3 | \`Hierarchy.levels\` emitted as flat array | Schema wants single recursive \`LevelType\`, not array |
| 4 | \`HierarchicalCode\` emitted name/names/description/descriptions | Schema's \`HierarchicalCodeType\` has no name/description fields |

Bug 1 needed full machinery (\`MemberValueType\` anyOf, \`CodeSelectionType\`, inclusive/exclusive selection variants). Bug 2 needed phase-ordering the reader so codelist index is built before concept-scheme reading so \`coreRepresentation\` Refs resolve in-message. Bug 3 needed writer/reader translators between flat \`ItemList[Level]\` ↔ recursive chain.

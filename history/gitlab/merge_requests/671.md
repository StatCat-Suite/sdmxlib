Closes #509.

`write_sdmx_json_data` (SDMX-JSON 1.0 and 2.0) defaulted `lang="en"`, the one place the library chose a language for the caller. `Dataset.sink_json` and `polars.write_data_json` didn't take a `lang` at all, so every message they wrote named itself English.

- **`lang` is now required** on all four. It picks the names a data message carries and fills `contentLanguages`.
- **New guard, `test_no_default_language.py`:** reads every function in `src/` and fails on a language parameter with a string default. It has a sabotage check.
  - It also found `Label` and `SideLabel` defaulting `lang` to `""`. No construction ever relied on that, so those defaults are removed too.
- **Call sites:** 36 test call sites now state the language they were already getting.
- **Breaking:** recorded in `upgrading.md`.

`just ci` is green.

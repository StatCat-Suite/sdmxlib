## Summary

\`RepresentationMixin\` gains a \`_codelist_cache\` slot, initialised to \`None\` in \`__attrs_post_init__\` and populated on first \`codelist\` / \`resolved_codelist\` access. Subsequent accesses short-circuit to a direct attribute read, skipping the \`isinstance(representation, Ref)\` check plus the \`Ref.__call__\` method dispatch.

\`invalidate_codelist_cache()\` is exposed for callers that mutate \`representation\` post-construction. The \`InMemoryRegistry\` Ref-interning pass updates the existing Ref in place (via \`_resolved = artefact\`) rather than reassigning the attribute, so no automatic invalidation is needed for the registry's resolution path.

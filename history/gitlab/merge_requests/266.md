Closes #289. Part of %16. **Baseline 166 → 96.**

#287 measured that substituting `Ref[object]` for `Ref[Any]` produced 56
errors, every one reading `Ref[Concept] cannot be assigned to Ref[object]`.
**Not one was a genuine loss of type information.** `Ref[T]` was invariant, so
`Any` was doing variance work while wearing the clothes of a gradual-typing
boundary.

Making the parameter covariant removes **55 of those 56** — the largest single
reduction in the milestone, and it came from a variance fix rather than from
chasing `Any` at all.

## You asked whether the checkers still disagree — they do

Re-measured on **pyrefly 1.2.0** / basedpyright 1.39.9, with the probe placed
*inside* the project so both used the real configs (my first attempt ran
pyrefly outside `pyrefly.toml`, which would have made the comparison
meaningless):

| shape | basedpyright | pyrefly |
| --- | --- | --- |
| mutable attrs, PEP 695 `[T]` | invariant | accepts |
| **frozen** attrs, PEP 695 `[T]` | invariant | accepts |
| frozen attrs, `Generic[T_co]` | ok | ok |
| mutable attrs, `Generic[T_co]` | ok | ok |

Two conclusions. The #201 finding **stands at 1.2.0** — an explicit covariant
TypeVar is still the only spelling both gates accept. And, new: **freezing the
class does not help.** basedpyright infers invariance from an attrs class
either way, so `Ref` stays `@define` and the change is the declaration alone —
no frozen fallout, no `object.__setattr__`, no eq/hash churn.

## Why covariance is sound despite a mutable field

`_resolved` is written in exactly one place — `_interning.resolve_ref`, which
is package-internal and only ever stores the artefact the URN already denotes.
There is no public setter, so the write path that would make covariance unsafe
is unreachable. That reasoning is now recorded at the class rather than left
for the next reader to re-derive.

The three factories take the parameter in argument position, so they get their
own method-scoped `U` and construct via `Ref(...)` rather than `cls(...)` — on
a covariant class `cls` is bound to `T_co` and cannot carry a factory's `U`
out. `Ref` is not subclassed, so nothing is lost.

## The one that stayed

`InMemoryRegistry._canonical_ref` keeps `Ref[Any]`, and it is exactly the case
CLAUDE.md reserves `Any` for: the interning table is heterogeneous while
`ref[T]` hands back the caller's `T`, so the parameter must be **recovered**,
not widened. Covariance cannot help there. Confining it to that accessor is
what kept it off the 55 signatures that only ever needed widening.

## Side effect

`MapEndpoint` was `Ref[Any] | MapDataType` and is now
`Ref[object] | MapDataType` — no `Any` at all. `src/` now has **zero** aliases
hiding one, and the test that pinned that inventory asserts it is empty.

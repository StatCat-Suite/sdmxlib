## Proposal: enable pyrefly's `unused-type-ignore` (needs your call)

`pyrefly.toml` currently disables it, with an accurate reason: *"pyrefly and basedpyright both honour `# type: ignore`, so neither can tell whether a comment is dead or is carrying the other one's error."* **That reason no longer applies** — the shared form is gone.

Measured: enabling it yields **0 errors**. And validated with a control, so zero means clean rather than the rule not looking — planting a deliberately dead `# pyrefly: ignore[bad-return]` produces:

```
ERROR Unused `# pyrefly: ignore` comment for code(s): bad-return [unused-ignore]
```

That would give both checkers a live dead-suppression check, which is what keeps this MR's result from decaying. `pyrefly.toml` is protected and was not modified — say the word and I'll do it as a follow-up.

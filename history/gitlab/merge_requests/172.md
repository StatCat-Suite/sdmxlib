Migrates the SDMX-JSON 2.0 **metadata message** (populated MetadataSets) off hand-rolled dict + orjson onto typed `msgspec.Struct` DTOs, matching the structure layer.

## What changed

- New DTOs `MetadataSetJson` / `ReportedAttributeJson` in `metadata.py`; `_to_*` converters on write, typed `msgspec.convert` + `_from_*` on read. orjson gone from this module.
- The recursive `ReportedAttribute.value` anyOf (`integer | number | boolean | string | localisedText | null`) is modelled directly as `bool | int | float | str | dict[str, str] | None` — msgspec keeps bool/int/float/str distinct on decode; a localisedText object → dict → `InternationalString`.
- Reuses the shared `_dto` foundation (`Meta`/`Sender`/`ENCODER`, `emit_istr`/`ingest_istr`). The shared `_camel_rename` moved into `_dto` so structure and metadata share one renamer.
- `version` is read-tolerant (`str | None` — real payloads like the TWG sample omit it; ingest defaults absent → `"1.0"`) while always emitted on write. Structure ref keeps the dual `metadataflow` / `metadataStructure` key handling.

## Conformance fix (bonus)

The old writer emitted `name` as a **dict**, but the metadata schema's `localisedBestMatchText` requires a **string**. Adopting the shared name/names split makes the emitted metadata valid against the official metadata JSON schema — locked by a new `test_metadata_set_recursive_attributes_conform`. (The metadata `VersionType` is strict 3-part SemVer, unlike structure's lenient one, so the fixture uses `1.0.0`.)

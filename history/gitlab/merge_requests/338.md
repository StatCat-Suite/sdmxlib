Sixteen sites read `type(root).__table__`, `__key__`, `__id__` and
`__constraint__`. Every structural accessor is a singleton whose
relation is a property of its type, so that was correct and invisible.

It stops being either at #297 step 4. A dataflow's observation table
comes from a *binding*, so two roots of the same class name two
different tables, and a class-level read cannot express that. The
alternative — synthesising a class per binding with `type()` — exists
and is worse.

Reading the instance costs the singletons nothing: a class attribute is
visible on the instance, which is why 5,227 tests do not move. The new
test states the reason and the property it buys, in the join module
where the behaviour lives rather than in a data plane that does not
exist yet.

Found while sizing step 4 rather than planned — the design doc's three
probes did not reach this far in, which is an argument for building the
next slice thin enough to keep finding these before they are expensive.

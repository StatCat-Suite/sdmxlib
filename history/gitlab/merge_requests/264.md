Closes #285. Part of %16. **Baseline 117 → 108.**

Fifteen sites, splitting three ways rather than one — which is the finding. A
blanket `dict[str, object]` sweep would have been wrong on a third of them.

## Two TypedDicts, where the shape is fixed

**`SpineRow`** — `_read_spine` returns the eight `sdmx.artefact` columns every
maintainable artefact shares, and **ten per-type readers pull 31 fields out of
it** between them. As an untyped map, a mistyped key was a `KeyError` at
runtime and a wrong value type was nothing at all.

Verified the guard is real rather than merely accepted:

```
$ # rename one read to meta["agency_idd"]
error: Could not access item in TypedDict
    "agency_idd" is not a defined key in "SpineRow"
```

**`AnnotationDict`** — `_annotation_to_dict` and `_parse_annotation` write the
same five keys out by hand in opposite directions. The TypedDict binds the two
halves: a key renamed in one and not the other is now a type error rather than
a field that silently stops round-tripping.

## Six to `dict[str, object]`, where nothing reads back

`to_dict`, its accumulator, and the three SDMX-JSON writers' `doc` / `data`
locals. Values go in, the whole map goes to an encoder — nothing needs the
erased type back out. All six took `object` with no narrowing required.

## Four keep `Any`, with the reason written down

This is where CLAUDE.md's litmus earns its keep. `object` was **tried** on all
four and produced 13 errors, every one a value flowing into a differently-typed
constructor parameter.

| site | why it stays |
|---|---|
| `_representation_to_dict` / `_parse_representation` | the Facet branch walks `attrs.fields(Facet)` and the parser mirrors it with `Facet(**kwargs)` — both generic over whatever the model declares. A TypedDict would restate twelve fields and go stale the moment `Facet` gains a thirteenth: a real drift risk traded for type information neither side consumes. |
| `from_dict` | the payload's shape depends on `cls`, so no single narrowing serves. This is the generic deserialiser; the typed entry points are the per-format readers built over it. |
| two `kwargs: dict[str, Any]` locals | already the pattern CLAUDE.md sanctions — confine the dynamic step to one annotated local so the `Any` dies there rather than riding out through a signature. |

**Every remaining `dict[str, Any]` in `src/` now carries a written reason.**

Migrates the SDMX-JSON **1.0** availability writer (`sdmx_json_1_0/writer.py`) off hand-built dicts + orjson onto typed `msgspec.Struct` DTOs.

## What changed

- New 1.0-specific Structs: `ContentConstraintJson`, `CubeRegionJson`, `ConstraintAttachmentJson`, `KeyValueJson`. The 1.0 wire spelling differs enough from 2.0 (`isIncluded` vs `include`, plural `dataProviders` array, inline Allowed/Actual `type`, `contentConstraints` key) that it warrants its own set rather than reusing the 2.0 DTOs.
- Reuses the shared `_dto` foundation (`Meta`/`Sender`/`ENCODER`, `emit_istr`, camel-rename).
- **Determinism preserved**: cube-region keyValues sorted by dimension id + values sorted lexicographically, no wall-clock timestamp unless `prepared` is passed — the bundle-cache byte-identity guarantee holds (`write() == write()` test green).
- `errors: []` stays always-emitted via the dict envelope; `isIncluded` / `id` / `agencyID` / `version` / `type` are REQUIRED so `omit_defaults` can't drop them.

All 7 writer tests pass; full unit suite **2427 passed**. No golden-byte test exists (tests decode-then-assert + a self-determinism check), so the encoder swap is transparent.

Closes #269. 21 of the benchmarks errored or failed on main, none of them
for a reason about performance: the fixtures build artefacts that the
stricter validation of this milestone rejects, so every case blew up on
its own setup instead of measuring anything.

Three causes, all in test code:

- `make_dsd` built a DSD with **no measures**, which SDMX-ML 2.1 has no
  representation for (#319) — so every parse / serialize / storage case
  that round-trips 2.1 refused the fixture. Given a measure, with a
  ConceptIdentity, and `OBS_VALUE` added to the shared concept scheme so
  reference validation still passes.
- `_big_codelist` left the codelist and all 100,000 codes unnamed, so
  `validate` collected 100,001 issues — a benchmark of *"how long to
  report that the fixture is wrong"*, not of validation.
- `test_our_wrapper_costs_almost_nothing_over_raw_sql` called
  `build_component_availability` without `api=`, required since #337
  because 2.1 and 3.0 disagree on the key's slot count and there is
  deliberately no default.

`just bench` is 122 passed, 1 skipped.

**New: `test_hierarchy_set_ops.py`**, the four shapes #348 reports, sized
to its 266,966-node hierarchy. Filed at 1.38 s / 0.39 s / ~40 s / ~220 s
against an older release; measured on main at 48 ms / 52 ms / 51 ms /
233 ms, the last of which also beats the hand-written SQL in that issue
by 3x. Three of its four asks already exist — `.ids()` and `.count()`
build no nodes, iteration is refused outright since #306,
`inherit_along_broader` and `ancestor_at` are pushed down, and
`.collect()` returns a frame.

These are wall-clock ceilings, which `docs/design/caching.md` normally
argues against. The exception it names is this one: every win here comes
from work staying in SQL, and an `.ids()` that regrew an object build
would return the identical answer. The ceilings are ~20x the measured
value so they fire on a change of algorithm, not a slow machine —
verified by breaking `ancestor_at`'s pushdown, which fails two of them.

The rollup test also asserts the map is *complete*, because a pushdown
that quietly dropped rows would be fast and wrong, and fast-and-wrong is
what a timing ceiling cannot see.

## The key finding

The issue flagged three wire quirks as needing a msgspec `dec_hook`. **None do** — all decode natively:

- **MemberValueType anyOf** (bare id string OR `{value, cascadeValues}`) → plain `list[str | MemberValueJson]`; msgspec disambiguates by JSON type.
- **`cascadeValues` `bool | "excluderoot"`** → plain `bool | str | None`, ingested to `CascadeSelection`.
- **inclusive/exclusive xs:choice** → two optional selection fields; ingest picks whichever is present → `InclusionMode`.

So this is clean plain-msgspec, no hook.

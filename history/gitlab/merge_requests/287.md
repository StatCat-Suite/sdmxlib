## Half of it resolved while the milestone ran

#267 moved the ref hierarchy into `model/_query_common.py` with plain names — CLAUDE.md rule 4, a private *module* holding plainly-named package-internal API, which is this issue's own **option A**. #294/#295 replaced the offending signature with `order_by(*keys: ColumnRef[...] | Descending[ColumnRef[...]])`.

Verified rather than assumed: walking every class `docs/api.md` renders turns up **no private name of ours** in any public signature. The single hit is `pathlib._local.Path`, which is where the stdlib defines a thoroughly public class on 3.13+.

## What was left is narrower, and is the part that bites

Those types were not importable from anywhere public. A user writing

```python
def sort_key() -> ColumnRef[CodeRow]: ...
```

had to reach into `_query_common`. Eleven types were in that state: `ColumnRef`, `Descending`, `Projection`, `AggregateRef`, `AggPredicate`, `FrameQuery`, `GroupBy`, and the four `RowKind` types. Now exported — **no code moved**, so option A's module split is unnecessary because it already happened.

## What stays private, deliberately

Leaf refs (`_IdRef`, `_AgencyRef`, …) — a user names the *base* the leaf satisfies; ten more per DSL would be ten unusable names. Accessors — reached through the singleton. Predicate subclasses — plainly named in the private module, not exported, with `Predicate` as the boundary. That is load-bearing: #254, #262 and #292 each changed that set, and each was free because no name was published.

The ecosystem check the issue asks for agrees: polars exposes `pl.Expr`, SQLAlchemy `ColumnElement` — the base, not the leaves.

## Guards

Four, in `tests/unit/test_public_surface.py`, covering both directions the issue names.

Keyed on `sl.__all__`, **not** `dir(sl)` — measured: with `dir`, removing `ColumnRef` from `__all__` did *not* fail the test, because `dir` sees any name the package happens to import. Verified discriminating after the change.

Scoped to the six query classes. Library-wide the same check also flags stdlib (`Callable`, `Optional`), polars (`Expr`, `LazyFrame`) and two of ours (`SupportsUrn`, `AncestorMap`) — a real but different question, filed as #299. Folding it in would make this guard mostly allow-list, which is a guard nobody maintains.

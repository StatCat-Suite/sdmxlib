Closes #517 (decision recorded on the issue).

`Dataset` now labels exactly as the query API does, in both signature and output.

**Signature.** `ds.collect(labels="en")` and `ds.lazy(labels=["en", "fr"])` take `str | Sequence[str]`, plus `label_suffix`.
- A bare string is one language.
- `with_labels=` and `lang=` are removed, with no shim.

**Output.**
- `FREQ` is kept, and `FREQ_label_en` is added beside it (plus `FREQ_label_fr`, and so on, per language).
- Before, the code column was replaced by `FREQ_label`.

**Implementation.**
- Everything goes through `sdmxlib.polars.label`, the same path `Query.frame(labels=)` uses.
- `_label_view` is deleted.
- Label columns are now text; the code columns keep their `pl.Enum`.
- A call that labels nothing raises, as the query API's does.

**Tests and docs.**
- New tests cover the columns, one language from a bare string, several languages, the suffix, and that a dataset's labelled frame equals `polars.label`'s.
- Updated: the data tutorial, the cookbook pages, `llms.txt` and `upgrading.md`. Their printed column names are checked by the doc test.

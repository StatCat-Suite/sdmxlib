## Design decisions worth reviewing

- **`Program` is a sequence, not `(pushed, residual)`.** For DuckDB every program has length one, so the pair looks sufficient through step 3 and fails at step 4, where REST answers a path predicate with two calls and a local step between.
- **`Capability.pushes` is keyed by path prefix**, so "can you scan `dsd` filtered by `components.concept.id`?" is askable separately from the whole predicate. Expensive to retrofit — it changes what the planner iterates over.
- **`PredicateShape` carries the fold.** A backend accepting `Match` at `Fold.NONE` has said nothing about `Fold.CASELESS`, and a case-sensitive server answering a caseless question returns too few rows silently (#222, #255).
- **Empty `bounding` means nothing bounds the backend**, not that everything does. `all(... for ... in ())` is vacuously true, which would grant an undeclared backend unlimited residuals.
- **`is_bounded` takes a `Push`, not a `Program`.** Trivially satisfied today; written now because the failure it will catch is a rewrite bounding the outer scan by a set from an unbounded inner one, which passes any whole-program check.
- **`rebase` is generic** (`copy.copy` + replace `_path`) rather than a case per column class. Reconstructing nine classes through their constructors means a class that gains a field silently loses it — producing a wrong query, not an error.

## Evidence, added as design sections

- **§10 — the survey.** #276's 76 hand-written sites as `sl.q` queries, run against a REST capability: 6 PUSHED, 7 REWRITE, 2 BOUNDED-LOCAL, 5 REFUSED. 75 % servable, and the refusals each name a fix. Kept as a test asserting the verdict *per shape*.
- **§11 — projection.** §9.4 guessed `select()`/`group_by()` would be unavailable over REST. Measured: `references=<type>` is a server-side join, so `/dataflow/ECB?references=datastructure` returns 102 flows + 81 DSDs in **one** request against 82. `Frame` needs no plan of its own; it contributes its prefixes to the fetch.
- **§12 — materialise or query through.** Break-even is about one query. Query through only for a single lookup you will not follow up.

## Two defects the evidence found in this branch's own code

- `shapes_of` flattened a `Quantified`'s parts into the outer shape set, mixing root-relative and child-relative paths — so prefix analysis read `("concept",)` as a path from the dataflow. No unit test could see it; nothing else did path analysis over a shape set.
- `is_bounded` was vacuously true for an undeclared backend (above).

## Corrections recorded rather than quietly fixed

Step 3 claimed the rewrite could not be checked before a second backend existed. Wrong: the rewritten form is already expressible as `is_in` over a sub-query, so both formulations run in DuckDB and can be compared. Nine predicate kinds agree, each on a partial answer.

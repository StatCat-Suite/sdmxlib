## `src/` changes

**Closed TypedDicts (171 `open-unpacking`).** A TypedDict unpacked with `**` into a constructor is only known to hold no other key if it is closed (PEP 728). `typing` gets `closed` only in 3.15, so this declares `typing-extensions`, which httpx already pulled in transitively; CLAUDE.md's dependency list is updated. A closed TypedDict cannot gain keys, so the three that others extend (`ReferenceAttrs`, `SpineKwargs`, the httpx options) are split into an open base plus closed shapes.

**Fields nothing initialized (64 `uninitialized-instance-variable`):**
- **Mixin fields.** `MaintainableArtefact`'s 9 fields and the component mixins' 5 were bare annotations. They are now read-only properties that the attrs subclasses' fields override, and the property bodies never run. I measured the alternative, a protocol base: it puts `typing`'s metaclass on every artefact class and makes an `isinstance` that misses go from 20 ns to 101 ns.
  - `_refshape`'s maintainable-field set used to read the annotations, so it now reads the properties. Emptying it fails 2 tests, so it is guarded.
  - `SupportsUri.uri` becomes a read-only protocol member. The writers only read it.
- **Query accessors (48).** Late-bound columns covering the tree relationships, the edges that reach back, and the facet group were annotations bound afterwards by `setattr`. That is the shape that let `_Concept` carry three edges with no binding (#307). Each is now a typed descriptor in the class body (`_Late`, `_FacetColumn`), so a declaration *is* its binding. pyrefly types `q.concept.ancestors` as `_ManyConcept[R]` through it, with no casts.
  - The accessor tests found these by annotation, so they passed vacuously after the change. They now find the descriptors and assert the exact count (33). I watched them fail on a dropped edge, a wrong path and a missing relationship.
- **One suppression.** `RepresentationMixin._codelist_cache` keeps `# pyrefly: ignore[uninitialized-instance-variable]`. pyrefly counts `__init__` and `__post_init__` as initializers but not attrs' `__attrs_post_init__`, which is what sets it. The repro is in the comment, and there is an upstream issue text ready to file.

**The 15 smaller findings:**
- A `match` on component kinds is now exhaustive through a `Literal` return type.
- `_each` takes an absent section, because `section or []` had left its lambda's parameter untyped.
- Owner lookups are typed `type[MaintainableArtefact]`.
- Enums in `canonical_key` are keyed by member name, since `Enum.value` is `Any`.
- One `match` states its `None` case.

**`implicit-any-lambda` is back on.** It had been off everywhere as a pyrefly 1.2.0 false positive. 1.4 fixed it: the recorded repro is clean, and `src/` and `bench/` have none.

## `tests/` fixed here

- The 16 `method-assign` sites patched methods by assignment; they now use `MonkeyPatch`. One of them drops a legacy `# type: ignore`.
- A `TypeGuard` applied to a discarded `type(obj)` now narrows a bound name.

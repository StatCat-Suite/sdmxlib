## The guard

Requires every difference to be declared with the 3.1 wire-format change that caused it. Four assertions, each earning its place:

- a body that **drifts apart** must be declared — the #345 shape;
- a declared divergence that **stops diverging** must be pruned, or the list becomes cover for the next real one;
- a function on **one side only** must be declared — the shape a body comparison cannot see at all;
- an **85% floor**, so the issue's own premise stays live: if 3.1 genuinely diverges later, the argument for a shared core weakens on its own evidence rather than by assertion.

#355's register counts two different facts as one number: a field the format
**cannot** carry, and a field it can carry that we **drop**. That makes its size
useless as progress — it *grew* for SDMX-JSON during the v0.50.0 work as invalid
output was converted into declared limits, the right change reading as the wrong
direction.

`KNOWN_DEFECTS` is now the half that can shrink, and it is **derived, not listed
twice**: whatever `unrepresentable()` claims is a limit, and anything left over
must appear there. A new `gaps.py` entry moves a line out without anyone editing
this file, and a *wrong* entry cannot hide a defect — it would have to describe
a field that really is lost.

## Making the two halves agree on paths

**`components[]` is not a thing.** I had declared the enumeration-format gaps
over `dsd.components`, a path the model does not have, so it matched nothing and
six real limits read as undeclared defects. Now declared per collection —
`dimensions[]`, `attributes[]`, `measures[]`.

**Three declarations stopped short of a target.** `measure_dimension` and
`release_calendar` were declared for SDMX-ML but not SDMX-JSON, which encodes
the same 3.0 model. `release_calendar` is the sharper case: SDMX-JSON **2.0
does** define it and **2.1 does not** — and our output must satisfy both, so
2.1's closed object model settles it.

**`reference_period` was undeclared, and is a limit.** 3.0 dropped
`<ReferencePeriod>` from the constraint types. The name still occurs in the 3.0
schema *set*, on a registration-query type in `SDMXRegistryRegistration.xsd` —
so a grep reads as "3.0 has this" and is wrong. I made that mistake before
checking which type owned it; the 3.1 writer's docstring had said "already
dropped in 3.0" all along.

**Nested paths** — `tree[].children[].name` is a different string from
`tree[].name` even though one `carried` predicate walks both. Both declared.

## Result

True remaining defects: **14 distinct paths**, down from 19 — and none of that
5 was a code change, only the register learning to tell the two facts apart.

`just ci` green: 5828 unit / 53 docs / 86 integration. Planting a fresh loss
makes it surface as unclassified rather than passing silently.

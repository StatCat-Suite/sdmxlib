**Phase 1 of milestone 11 — closes #227.** Fixes one thing and measures the rest.

## The invariant

For every artefact kind sdmxlib models and every wire target, `serialize` must either produce a document that validates against the official schema, **or** raise `ValidationError` naming what cannot be represented.

Silently emitting an invalid document is the worst of the three outcomes: the call succeeds, the bytes look plausible, and the first sign of trouble is a consumer rejecting the file — by which point sdmxlib is nowhere in the stack trace.

## The burn-down

`KNOWN_INVALID` records the **24 (artefact, format) pairs** that fail today, across 11 artefact kinds, each with the element and the child the schema wanted. Phase 3 (#229) removes entries; the milestone closes when the table is empty.

Entries are asserted **still broken**. An exemption that outlives the bug it describes is worse than no exemption, because it goes on granting permission nobody re-examines — so fixing one fails the gate until the entry is deleted.

Verified in both directions rather than assumed:

| control | result |
|---|---|
| bogus entry for a pair that serialises fine | fails ✓ |
| delete a real entry | fails ✓ |
| revert the DataStructure fix below | fails ✓ (both tests) |

## The one fix

Serialising a measure-less `DataStructure` to 2.1 raised a bare `ValueError` from **inside the writer, mid-document**. The rule was right — `MeasureListType` requires a `<PrimaryMeasure>`, so such a DSD has no 2.1 encoding — but it fired after `serialize` had already decided the message was writable, which is the wrong place to learn that it is not. Now a `ValidationError` at the write boundary like every other refusal.

`test_refusals_are_validation_errors` holds that line: a refusal must carry inspectable `.issues`, not merely be *some* exception that escapes a writer.

## Guards

Two completeness checks keep the gate honest as the model grows: every `StructureMessage` field must have a bare artefact, and `KNOWN_INVALID` may only name real fields and real wire versions — a typo'd key would exempt nothing while looking like it exempted something.

## Scope

Bare artefacts are the floor, not the ceiling. This catches missing **required children**. Constraints that only bite on *populated* artefacts — uniqueness, required and prohibited attributes — are phases 4 (#230) and 5 (#231).

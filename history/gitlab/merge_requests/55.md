Phase 1 of formal XSD-based validation of writer output. Additive only — no production code touched. Lands the infrastructure so phases 2 (3.0 wiring) and 3 (2.1 wiring) can validate the writer round-trips and the hand-written input fixtures.

## What's added

### Vendored schemas
- \`tests/schemas/sdmx_ml21/\` — 58 XSDs from \`sdmx-twg/sdmx-ml@v2.1\` (~1.2 MB)
- \`tests/schemas/sdmx_ml30/\` — 30 XSDs from \`sdmx-twg/sdmx-ml@v3.0.0\` (~700 KB)
- \`tests/schemas/VERSION\` — pinned upstream tags + retrieval date
- \`tests/schemas/README.md\` — attribution + refresh instructions

The flat-per-version layout matches upstream, so lxml's \`etree.XMLSchema\` resolves \`<xs:include schemaLocation=\"...\"/>\` from each file's own directory with no catalog manipulation.

### License note
Upstream sdmx-twg/sdmx-ml has **no LICENSE file**; the XSDs carry only a \`Copyright SDMX 2021\` notice. README documents the practical convention SDMX standards are published under (intended for free implementer use) and the source commit. If SDMX publishes formal terms, the README will be updated to match.

### Verified not packaged
\`uv build\` ships only \`src/sdmxlib/\` in the wheel and sdist — confirmed by inspecting the built artefacts. No extra build config needed.

### Helper module
- \`tests/support/xsd.py\`:
  - \`compile_structure_schema(version) → etree.XMLSchema\`
  - \`assert_valid_sdmx_ml(xml, schema)\` — raises AssertionError with a multi-line line-numbered error log (more readable than lxml's truncated default).

### Session-scoped fixtures
\`tests/unit/conftest.py\`: \`sdmx_ml21_schema\` and \`sdmx_ml30_schema\` fixtures compile the schemas once per pytest invocation (~100 ms each, amortised across all consumers in phases 2/3).

### Smoke test
\`tests/unit/test_xsd_schemas.py\` — confirms both schema sets compile. If these tests fail, the whole validation pipeline is broken; surfaces the schema-set problem before any writer test points at it.

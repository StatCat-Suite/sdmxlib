The projection plan returned by `select(...)`, `group_by(...).agg(...)` and `agg(...)` was called **`Frame`**, which clashed with the `.frame()` method that *runs* a query into a `pl.DataFrame`. It is renamed **`Select`**, as decided on #516.
- `Select` is SQL's word for the statement, and SQLAlchemy uses the same name for the same object.
- `.frame()` is unchanged. It is the name callers actually type (42 times in the docs, where `Frame` appeared only in prose).
- There is no alias. Source, tests, typing probes, `api.md`, the design pages, the llms files and the README are updated, and `upgrading.md` records the rename.

The readers fetched the children they knew by name and never looked at the rest, so an unexpected element vanished. Eurostat's 3.0 AgencyScheme uses `<str:Name>` where the schema requires `<com:Name>`. It came back with no name at all, and `validate()` refused it later for a reason one step removed.

## Decided design

- **An allowed-children table derived from the vendored XSDs.** Not full XSD validation, which would refuse whole real documents over value-level quirks such as #432's `_T`, and would mean shipping XSDs that carry no explicit licence.
- **An artefact that breaks the table is refused** through #435.

## What changes

- **The generator.** `tools/generate_allowed_children.py` resolves:
  - named and anonymous types;
  - extension (appends to the base) and restriction (replaces it);
  - nested sequence, choice and all;
  - groups and element refs;
  - transitive substitution groups;
  - element `form`.

  `xs:any` makes a parent open, and a parent declared in several contexts gets the union of its children. Output is `formats/sdmx_ml/_allowed_children.py`: 2.1 has 204 parents, 3.0 has 224, 3.1 has 217. Regenerate with `just generate-allowed-children`; a test fails if it drifts from the XSDs.
- **The check.** `formats/sdmx_ml/_closed_world.check_artefact` walks an artefact's subtree with `iterwalk`. It raises `SdmxConformanceError` at the first element its parent does not allow, naming the element, the parent, the line, and what the schema allows there:

  > `<str:Name>: not allowed in <str:AgencyScheme> (line 10); the SDMX-ML 3.0 schema allows com:Annotations, com:Description, com:Link, com:Name, str:Agency there`
- **Wiring.** All 25 SDMX-ML reader loops run it through `build_each_xml`, before building, so the refusal names the stray element rather than its downstream symptom.

**Cost:** 9–14% of parse time, measured A/B/A interleaved (e.g. OECD 2.1 codelists 1.79 s → 2.05 s). It started at 20–25% and was brought down by re-keying the table at import and walking with `iterwalk`.

## Tests

`test_closed_world.py` has 42 tests:
- Eurostat refused, and read once the name is `com:Name`;
- `<str:Bogus>` in 2.1 and 3.1 refused at the exact line;
- comments ignored;
- the fixture corpus and the maximal round trip clean;
- the drift guard;
- table sanity (substitution, restriction, extension, an open parent).

Sabotage-checked: turning the check off fails 5, removing `com:Name` from 3.0 AgencyScheme fails 7, and adding `str:Name` fails 4.

First MR of #422: the read-side register. Later MRs model each construct and delete its row.

## Decisions (asked)

- **Register first**, then model row by row with a strict-xfail burn-down.
- **On read, keep the artefact and record the loss.** Default `parse` doesn't raise on a loss; `lossless=True` does. An artefact the model has no class for is a refusal, since there's nothing partial to keep.

## What changes

**`formats/sdmx_ml/_losses.py`**, the read-side twin of `formats/gaps.py`:

- **`LOSSES`** has ten rows, each with the XPath that counts the construct under an artefact element:
  - `com:AnnotationURL` (repeated) and `com:AnnotationURL/@xml:lang`;
  - `com:Link`;
  - N:M `str:ComponentMap`;
  - cube-region `@validFrom`/`@validTo`;
  - `str:SentinelValue`;
  - DSD `LocalRepresentation/@maxOccurs`;
  - `str:MeasureRelationship`;
  - `str:MetadataAttributeUsage`;
  - `str:Dimension/@position` when it disagrees with document order.

  A hit is recorded as `sl.ReadGap(urn, construct, count, reason)` on the new `StructureMessage.lost`.
- **`account()`** checks the whole document: every child of every `mes:Structures` container must come back built or refused. Anything left over is refused:
  - "sdmxlib does not model X" for a class the model lacks. That covers #422's rows 2–4 and 14, plus OrganisationSchemeMap, ReportingTaxonomyMap and 3.1's AvailabilityConstraint.
  - "reader defect" for a class the model has but the reader skipped.

  Only sdmxlib's own synthetic 2.1 StructureSet is exempt.
- **`parse` / `read(..., lossless=True)`** raises `sl.LossyReadError`. It's a subclass of `SdmxParseError` and carries `.lost` and `.message`. Nothing is interned when it raises.

**Behaviour change:** a document holding an unmodelled artefact now fails a default `parse` with `SdmxConformanceError`, where the artefact used to be skipped. `strict=False` reads the rest.

Not covered yet: the SDMX-JSON reader reports neither losses nor unmodelled artefacts. That's a follow-up #422 MR.

#436's closed-world check couldn't catch any of this. It refuses elements the schema forbids, never reads XML attributes, and never walks `mes:Structures`.

## Tests (`tests/unit/test_read_losses.py`)

- **Discrimination:** the maximal message round-trips with nothing lost or refused in 2.1, 3.0 and 3.1.
- **Every row × 3.0/3.1:** injected into the maximal message's written form, reported exactly once, and the artefact is kept.
- **Strict xfail with `raises=AssertionError`:** the row's own XPath counts the construct again after a write. All 20 cases currently fail on the count (`0 == 1`). Model a construct and its case passes unexpectedly, which forces its row out.
- **Unmodelled classes:** the exact list per version is derived from the schema table, and each one is refused while the rest of the document is read.
- **Sabotage check:** blanking the codelist reader produces a "reader defect" refusal.

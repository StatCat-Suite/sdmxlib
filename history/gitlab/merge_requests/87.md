## Observation worth a follow-up (not in scope)

The DSL's \`node.annotations[type] == \"...\"\` predicate filters against \`Annotation.title\` (a plain \`str\`), not \`Annotation.text\` (the \`InternationalString\` SDMX convention). A user who only sets \`text={\"en\": \"Province\"}\` gets zero matches with no error. The fixture in this MR sets both fields so the test reflects realistic SDMX-style annotation data; the gap itself is real and worth opening as a separate DSL-usability issue.

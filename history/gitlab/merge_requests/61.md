## Conformance bugs fixed

### 1. \`isFinal\` on MetadataStructure and Metadataflow
Both writers went through \`_write_maintainable_attrs\` which sets \`isFinal\`. SDMX 3.0 dropped \`isFinal\` from \`MaintainableType\` — both elements now set \`agencyID\`/\`id\`/\`version\` directly.

### 2. Metadataflow \`<Structure>\` emitted as wrapped \`<Ref/>\`
Per \`MetadataflowBaseType\`, Structure is \`MetadataStructureReferenceType\` — URN-text per 3.0 convention. Now emits via \`_write_urn_text\`.

### 3. Metadataflow \`<Target>\` was never emitted at all
Per \`MetadataflowType\` extension, **at least one** \`Target\` (URN-text, \`WildcardUrnType\`, unbounded) is required for XSD validity. The model now carries \`targets: tuple[str, ...]\` (raw URN strings — the type permits wildcards so a resolved \`Ref\` isn't always meaningful); reader populates it, writer emits each.

Smaller alignment fixes alongside:
- MetadataAttribute \`minOccurs\` reader default was \`\"0\"\`; XSD default is \`\"1\"\`. Aligned.
- Writer emitted \`minOccurs\` when the value was 0 and omitted it when 1 — inverted to match the XSD default-suppression convention.

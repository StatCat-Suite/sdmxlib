## Two guards that could not fail

- **`test_field_coverage` had never compared a text.** The census compared mappings only through `isinstance(…, dict)`, and `InternationalString` has never been a `dict`. So a text was walked as the sequence of its *keys*. Every name and description compared equal to any other in the same languages, in every format, since the census was written (#354). Twelve survivors read a description from `<com:Name>` and passed. The census now compares text, and has a discrimination test that fails against the old branch. With the fix in place, the suite finds no text defect.
- **`xs:boolean` was read under four rules.** `leveled="1"`, `isFinal="1"`, `hasFormalLevels="1"` and others read false, and `isInclusive="0"` read true. Every read now goes through `_common.flag` / `optional_flag` / `required_flag`, and a scan fails on a fifth rule.
  - The reader-defaults census (#474) now counts `flag` calls. That surfaced `isRESTDatasource` and `isWebServiceDatasource`: `use="required"` in every XSD, yet read as false when absent. A data source missing one is now refused.

**The rest are real.** The clearest example:

That module is **97% line-covered** — every line runs — and the *content* of its diagnostics is unpinned. That is exactly the class of gap coverage cannot see, and it is why #212's finding that the 19 assertion-free validation tests are "sound because paired negative tests exist" was worth checking separately: the negative tests prove `validate` still raises, not that it says anything true.

## Two setup findings, both of which cost time

**`source_paths` must be the import root**, `"src"`, not the package directory. mutmut inserts it directly into `sys.path`, so `"src/sdmxlib"` puts the package *contents* top-level and `sdmxlib/_duckdb.py` shadows duckdb's own `_duckdb` C extension. I initially called that a latent footgun in sdmxlib — **it is not**, it was purely my misconfiguration, and I corrected that claim.

**`mutate_only_covered_lines = true` is unusable here.** Same collision from the other direction: its coverage pass runs pytest in-process first and leaves `sys.modules` in a state where duckdb can no longer be imported. The config records why it stays off and what that costs — uncovered lines get mutants too, which survive for uninteresting reasons, so the 78% is a floor.

## Cost and placement

**Local only, never CI.** 11 minutes against a 16 s suite is not something to put in a cost-constrained manual pipeline. `just mutate`, `just mutate-results`, `just mutate-show <mutant>`.

**No production code changed**, per the issue. Findings become follow-ups.

## What this feeds

#test-8 asks adopt / narrow / drop, and deliberately sequences a **re-run after the Hypothesis work** so the same mutants can answer whether property-based tests kill more than example-based ones. This run is that baseline: **78%, with `validation.py` carrying 80% of the survivors.**

My reading so far — worth a second opinion — is **narrow, not broad**. The signal was strong where the code is logic and weak where it is formatting, so the value is in running it on a module you are actively changing rather than across the codebase.

## Bug surface fixed in this MR

### DSD components
- \`localRepresentation.textFormat\` → \`localRepresentation.format\`
- Inside format: \`textType\` → \`dataType\`
- \`attributeRelationship\`: drop \`dataSet\` (not in spec) — fall back to \`dataflow: {}\` per SDMX 3.0+; \`dimensions\` is array of dim-id strings (was \`{componentId: ...}\` wrappers)
- \`groupDimensions\` is array of strings

### DataConstraint
- \`constraintAttachment\`: scalar URN → array per kind (\`dataflows\`, \`dataStructures\`, \`provisionAgreements\`)
- Drop \`type\`, \`releaseCalendar\`, \`referencePeriod\` (not in spec)

### StructureSets distribution
- Drop the synthetic \`structureSets\` wrapper at \`/data\`
- Maps live at top-level per kind: \`representationMaps\`, \`structureMaps\`, \`conceptSchemeMaps\`, \`categorySchemeMaps\`
- Each map carries its own \`agencyID\` + \`version\` (the wrapper used to supply these)

### RepresentationMap (the most invasive)
- \`source\` / \`target\`: array of reference objects keyed by \`codelist\` (was scalar URN string)
- Value entries live under \`representationMappings\` (was \`codeMaps\`)
- Asymmetric value map: \`sourceValues\` is array of MappedValueType objects (\`{value: <str>}\`) while \`targetValues\` is array of bare strings

### MetadataAttribute maxOccurs
OccurenceType: positive int OR the literal string \`\"unbounded\"\`. Writer emits \`\"unbounded\"\` when the model has None; reader handles the inverse.

### Smaller fixes
- ProvisionAgreement: \`structureUsage\` → \`dataflow\`
- Codelist: don't emit empty \`codes: []\` — schema requires non-empty when present

## Backwards compatibility

Reader continues to accept all legacy field shapes (\`textFormat\`/\`textType\`, scalar URN attachment fields, \`structureSets\` envelope, \`codeMaps\`, \`structureUsage\`, etc.) so previously-written sdmxlib JSON still parses.

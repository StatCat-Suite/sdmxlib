## What became typed, and what deliberately did not

The **declaration** half of a data message has a fixed shape in both SDMX-JSON 1.0 and 2.0, so it now decodes into Structs: `ValueEntryJson`, `ComponentDeclJson`, `ComponentLevelsJson`, `StructureBlockJson`, `DataSetBlockJson`, plus a per-version envelope (1.0 keeps `structure` as one top-level block; 2.0 nests an array under `data`).

The **observation** half stays `list[Any]`. An observation array holds a measure of arbitrary JSON type followed by integer attribute positions — heterogeneous by nature rather than by omission, which is the verdict #200 already recorded for `list[Any]`.

msgspec ignores unknown keys, so the extra fields our own writer emits (`keyPosition`, `relationship`, the time-bound `start`/`end`) are tolerated without being modelled.

## Three behaviour fixes

Each has a test that **fails on `main`**.

**1. The v1 reader violated its own documented contract.** `{"structure": null, ...}` and `{"structure": "x", ...}` raised `AttributeError: 'NoneType'/'str' object has no attribute 'get'` — but the docstring says `Raises: ValueError`. Both now raise `ValueError`. `msgspec.ValidationError` **is** a `ValueError` (checked, not assumed), so typed decoding satisfies the contract whichever path fails.

**2. Silent data corruption.** A value entry of `{"id": null, "name": "Annual"}` decoded to the literal string `"None"` as a dimension value, because the label picker tested key *presence* and then `str()`'d the result:

```python
if "id" in value_entry:          # true for an explicit null
    return str(value_entry["id"])  # -> "None"
```

It now tests for a value and falls through to `name`. Nobody would have seen an error — just a `"None"` in their frame.

**3.** `_decode_dataset_attrs` expressed "not int-convertible" implicitly via `int(raw)` raising `TypeError`. With the slot typed `object` that becomes an `isinstance` gate — same three outcomes (resolve / fall back to raw / pass through), now checkable. The `str`-index case (`"0"`) still resolves, which an `isinstance(raw, int)` gate alone would have broken.

Audit of `ruff.toml` / `pyrefly.toml` against the recent ruff 0.16 and pyrefly 1.2 releases, plus the code fixes the tightened configuration surfaced. Every config subtraction carries the measured count that justifies it.

## Why now

`uv.lock` is gitignored (published library), so CI resolves the dev group fresh every pipeline. An unbounded floor lets a checker release land with no commit of ours in between — and with ruff on `select = ["ALL"]` that was not hypothetical: **0.16.0 stabilised 12 preview rules and would have turned CI red on the next run** (`PLR0917` ×7, `RUF036` ×1). All three checkers now carry upper bounds; ruff 0.15.8 → 0.16.1, basedpyright 1.38.4 → 1.39.9.

## ruff

- Dropped `fix = true`. A config-level fix flag means any bare `ruff check` rewrites the tree, and "safe" is not always semantics-preserving — FURB152 rewrote a literal `3.14` in a test assertion to `math.pi`. Fixing stays opt-in via `just fmt`.
- `ANN401` no longer ignored wholesale. The stated rationale ("Any is legitimate for `**kwargs`") was false — `allow-star-arg-any` changed the count by zero. It now enforces the typed-core/untyped-shell boundary, with `formats/` `storage/` `local/` exempted per-file. The 12 model-layer sites are fixed in code.
- `FBT` un-ignored (3 real sites). `PLR0913` stays off but with the real reason: it counts keyword-only args; the smell is positional count, which is `PLR0917`, now capped at 8 and clean. `B008` dropped as dead.

## pyrefly

Moved from an implicit-any allow-list to `preset = "all"` plus an annotated deny-list — the same governance shape ruff already runs under, so new error kinds arrive visible rather than silently not running. This also unhid pyrefly's warn tier: the previous "0 findings" was sitting on 18 unread warnings.

## Code fixes surfaced, none suppressed

- 31 missing `@override` (PEP 698).
- 11 `Any` escaping a declared return type — bare `msgspec.json.decode` (now typed), `getattr` on thread-locals (now annotated), two unannotated `make_lazy_*` factories.
- 17 redundant `int()`/`bool()`/`str()` conversions. **Three were sanitising casts standing in for bind parameters** — `f"LIMIT {int(n)}"` in `code_query`, `hierarchy_query`, `data_store` — now parameterised, which is what the SQL-style rule asked for.
- `_build_representation` took 13 positional args including two bools; now two positional, rest keyword-only, and its `-> Any` is a real union.
- A deprecated `@contextmanager` `Iterator` annotation, and `_codelist_cache` declared inside `__attrs_post_init__`.

## Suppression hygiene

`reportUnnecessaryTypeIgnoreComment` is on and removed 12 dead comments. Two of those removals exposed findings pyrefly had been swallowing (`Session.extract` returning `Any`, `attrs.has(cls)` erasing `T` in `from_dict`) — both fixed. Since both checkers honour `# type: ignore`, that shared form is unattributable; the policy is now each checker's own syntax.

Also on as zero-hit regression guards: `reportInvalidCast`, `reportDeprecated`, `reportUnsafeMultipleInheritance`, `reportTypeCommentUsage`, `reportSelfClsParameterName`. Deliberately off with counts recorded in `pyproject.toml`: `reportImplicitOverride` (its 26 extras are all object-dunder overrides — pyrefly owns overrides), `reportPrivateUsage`, `reportUnnecessaryIsInstance`, `reportUnnecessaryComparison`.

## Suppression gate

The `.claude` PreToolUse hook missed ruff's block suppressions (`# ruff: disable|enable|ignore|file-ignore`, stabilised in 0.15/0.16), which silence a *range* rather than a line. Regex extended; `.claude/settings.json` is now tracked so the gate ships with the repo.

## Docs test

Fixes a docs test that asserted a shape the model no longer permits: `MetadataSet.structure` takes a Metadataflow or MetadataProvisionAgreement, never a bare MSD. The test now distinguishes the two real kinds and pins the rejection; the cookbook section it mirrors moved with it.

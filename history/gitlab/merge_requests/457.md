`resolve.map_to_istring` under that name; this one is a leftover of the
relational-schema move and has been unreachable since.

empty case where the live one returns the shared `EMPTY`. So it is both dead
and, were it not, wrong in the way that issue fixed — which is the argument for
deleting rather than correcting it.

#154's close-out. Nothing else in that profile is worth changing: see the
issue.

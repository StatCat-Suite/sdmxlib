Closes #488.

The main-line half of the fix: !615 carries the same commit to `release/0.67.x` for the 0.67.1 patch, and this brings it forward so 0.68 does not lose it. Cherry-picked unchanged (`-x`); it applies to main without conflict.

A data message wraps a dataflow, but the dataflow's annotations never reached it — `structure.annotations` held only component and value annotations (#366). .Stat's Data Explorer reads `NOT_DISPLAYED`, `LAYOUT_FLAG` and `LAYOUT_NOTE` only from that pool. Both SDMX-JSON data writers (1.0 and 2.0) now pool the resolved dataflow's annotations first, so their indices are fixed before the dataSet head is written, and reference them from `dataSets[].annotations` (an integer array in both schemas). An unresolved ref, or a dataflow without annotations, adds no keys.

`tests/unit/test_sdmx_json_data_annotations.py` passes on main (19).

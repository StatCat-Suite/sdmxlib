## `just mutate` was dead, not degraded

Six tests read a file by a working-directory-relative path:

```
docs/api.md                                        test_public_surface.py     (#265)
src/sdmxlib/sql.py, src/sdmxlib                    test_compile_context.py
tests/schemas/sdmx_json/{1.0,2.0}/samples/...      test_sdmx_json_data_readers.py
tests/fixtures/sdmx_ml21/ecb_dataflow.xml          test_xsd_conformance.py
```

mutmut copies `src/` and `tests/` into a `mutants/` tree and runs pytest there. It copies **not** `docs/`, so `docs/api.md` does not exist. The read happens at *import* time, so it raised during mutmut’s stats pass and aborted the entire run:

```
ERROR tests/unit/test_public_surface.py - FileNotFoundError: ... 'docs/api.md'
failed to collect stats. runner returned 1
```

Zero mutants ran. `just mutate` has been broken since #265 landed and nothing surfaced it, because mutation is deliberately outside `just ci` — so between #265 and now, no run happened that would have noticed.

## Fix

`tests/support/repo.ROOT`. It cannot anchor on `__file__` alone, because under mutmut that points inside `mutants/tests/support/`. It walks up for a directory holding **both** `pyproject.toml` and `docs/` — the pair the mutants tree fails, so the walk continues past it to the real checkout.

## Guard

`test_suite_is_relocatable.py`, a static AST scan for string literals starting `docs/`, `src/`, `tests/`… passed to `Path()` / `open()`. Static rather than runtime because the failure is a *collection* error: a runtime assertion cannot fire in a run that already aborted.

It carries its own discrimination test — a scan that walks the wrong tree or matches nothing passes silently forever, so the guard is fed the exact spelling that broke #265 and asserted to flag it. The scan only catches the literal form; `Path(f"tests/{x}")` slips through, and the docstring says so. All six real sites were literals.

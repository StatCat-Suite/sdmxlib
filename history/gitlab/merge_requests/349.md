catalog.observations(flow_urn).select(...).collect(labels=["en", "fr"])
    #  REF_AREA │ OBS_VALUE │ REF_AREA_label_en │ REF_AREA_label_fr

An argument on `collect` / `frame` rather than a `.labelled()` clause,
because every other link in the chain compiles to SQL and this one runs
over the materialised frame. Saying so in the signature of the call that
materialises keeps the refinement chain meaning one thing.

**The language is always in the name**, including for a single one:
`REF_AREA_label_en`, never `REF_AREA_label`. Otherwise adding a second
language *renames* the first column and a purely additive change breaks
whatever read it. `label_suffix=` renames the middle part for a caller
who wants `REF_AREA_name_en`.

**An aliased column is labelled under its alias.** `select(area=...)`
gives `area_label_en`: the name in the frame is the name a caller reads.
That needed the projection's alias map, which only the projection knows,
so `label` grew a `columns=` mapping from component id to frame column.

**A query with no DSD refuses.** A store cannot resolve one, so a
store-built query says to use `catalog.observations` rather than
returning unlabelled rows — the failure this whole thread started from.

`label`'s "nothing to label" refusal is now the strong form: it fires
when no *label column was produced*, not merely when no component names a
column. A projection of components that are all non-enumerated used to
slip through the weaker check and produce nothing, silently. The two
cases get different messages, because the fixes differ — rename the
columns versus project something enumerated.

`Dataset.lazy(with_labels=True)` keeps `{col}_label`, and that is not an
oversight: it *replaces* the code column, so there is exactly one
language by construction and none can arrive to make the name ambiguous.
Recorded where a reader would compare the two.

Two guards earned their keep. `test_no_unreviewed_collection_parameter`
caught `labels: str | Sequence[str]` as the #261 shape — a bare `str`
satisfies `Sequence[str]` — and `labels="en"` is now pinned as one
language rather than two characters. The public-surface guard caught
`Sequence` leaking into a signature.

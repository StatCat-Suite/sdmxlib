Step 2 of #516: sinks on `ObsQuery`.

- `obs.sink_parquet(path, chunk_rows=)` writes Parquet. Each batch becomes a row group.
- `obs.sink_csv(path, chunk_rows=)` writes plain CSV, a column per component, with a single header across batches.
- `obs.sink_json(path, *, lang, version="2.0", message_id=, prepared=, sender_id=, chunk_rows=)` writes an SDMX-JSON 2.0 or 1.0 data message. It takes the same arguments as `Dataset.sink_json`.

**Typed per batch.** All three sinks read `stream()` and cast each batch from the DSD using the same `_typed` as `frame()`, so memory stays bounded. `stream()` stays raw.

`Dataset.sink_json` was not streamed: it collected everything and then re-batched. These sinks stream.

**Behaviour:**
- A value that doesn't fit its type raises the same `ValueError` as `frame()`, naming `.stream()` and `validation_report`.
- An empty result still writes its columns.
- `sink_json` refuses a query that has no structure.

**Tests** store values as text (`'1.50'`), so the asserted `1.5` can only appear if the cast ran. Sabotage check: with the cast removed, 8 of the 13 tests fail.

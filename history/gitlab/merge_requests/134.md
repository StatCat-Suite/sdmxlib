Tier 1 of the **Typing hardening** milestone (#165 #166 #167 #168) — narrow the model-core seams where a named type already existed and `Any` was reached for out of convenience. Milestone philosophy: safe & self-contained first.

## Changes

- **#165 — registry write seams typed `HasUrn`**: `InMemoryRegistry.add`/`add_all`, `Registry.add`/`add_all`/`replace`. They already `isinstance`-check `HasUrn`; now it's a static contract too.
- **#166 — heterogeneous stores narrowed off `Any`**:
  - `InMemoryRegistry._store`/`_by_type` → `dict[str, HasUrn]` / `list[HasUrn]` (the sole writer is `add(HasUrn)`, so this is the *precise* honest type — and it types `Registry.ingest`'s `_store.values()` with no cast). Reflective walkers take `object`.
  - `Session._map`/`_resolved_map` → `dict[str, object]` (store + get-return only; the `object→T` narrowing stays localized to `get()`). `_latest`/`_resolved_latest` → `dict[str, Maintainable]` (compared on `.version`).
  - `Registry._load_parent_scheme` → `object | None`.
- **#167 — `ItemList[T: HasId]`**: new one-property `HasId` protocol bounds the element type, deleting the `getattr`/`cast`/`# pyright: ignore` dance in `__init__` and `ids()`. This encodes a real SDMX IM invariant — an `ItemList` holds *identifiable items only*. `Contact` (a non-identifiable complex type, no `id`) is correctly a `tuple`; two test fixtures that wrapped contacts in `ItemList([contact])` were a category error and are now `(contact,)`.
- **#168 — `to_dict[K]` overload**: a key function recovers its return type — `to_dict(lambda c: c.id)` is `dict[str, T]` instead of `dict[Any, T]`.

## Incidental fixes surfaced by the narrowing (the `Any` was hiding them)

- **`HasUrn` protocol was subtly broken**: `agency_id`/`id`/`version` were bare *mutable-attr* members, so artefacts that **derive** them via `@property` (`MetadataSet`, `DataflowBinding`) never actually satisfied `HasUrn`. Changed to read-only `@property` members (mirrors `Maintainable`) — now they do.
- **`Registry._local_cache_lookup`**: replaced a `contextlib.suppress(TypeError)` around `add()` with an explicit, type-safe `if isinstance(cached, HasUrn)` guard (the precise equivalent).

## Deferred (not this MR)

- **`artefact_urn` kept `Any`**: narrowing it to `HasUrn` surfaced a latent runtime bug — `hierarchy_query` passes a bare `Code` to `artefact_urn`, but `Code` isn't maintainable (no `agency_id`/`version`), so it would `AttributeError`. Filed as **#174** rather than papered over. `artefact_urn` narrowing rides along with that fix.

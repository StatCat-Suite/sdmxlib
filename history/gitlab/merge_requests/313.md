Relates to #312. Step 4b. The REST backend answers queries end to end; corpus byte-identical.

It issues the requests a program names, writes what comes back into a store, and hands the **original** query to the compiler that already exists. No local predicate evaluator, no sort, no projection — §13's claim, now running.

## The gate

A fetch one relation short does not fail: the query runs against a store missing a table and returns nothing, with no error anywhere. So the differential compares a store loaded with the **whole catalogue** against one loaded only with what the planner chose to request. Verified to have teeth — forcing `references_for` to return `"none"` fails 8 tests across three files.

That is only a real test because `FakeRestService` computes `references=` from the SDMX meaning — walking `Ref` fields — rather than by asking `_closure` what it wanted. A fake that served whatever was asked could never disagree.

## Three things the fake had to get right

Each first presented as "the executor fetches short", which is the confusion this area keeps generating:

- **A component references a concept _item_** (`…CS(1.0).REF_AREA`), and no service returns a bare item — it returns the ConceptScheme containing it. Without resolving urn to owner, `children` omitted the scheme.
- **`ItemList` is not a list.** Walking only `list`/`tuple` found no references on any artefact, so `children` behaved exactly like `none` and the fake agreed with a broken closure.
- **The message field per artefact kind** is parsed from the `StructureMessage` annotations rather than written out. A kind with no home would be dropped silently, and the test meant to catch a short fetch would itself be fetching short.

## Also

- The fixture pins #279 in passing: `Dimension(concept=<Concept>)` is silently dropped by the writer, so the catalogue builds components from a `Ref` and says why.
- The refusal is asserted to come **before** the network. A backend that fetched and then discovered it should not have has already paid the cost the rule exists to avoid.

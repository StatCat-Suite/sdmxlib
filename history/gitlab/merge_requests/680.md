Step 3 of #516: `obs.validate(chunk_rows=100_000)` lists every value that its component's codelist doesn't contain, with a count for each. It returns the same `column / invalid_value / count` frame as `Dataset.validate()`.

**How it works.** It reads `stream()`'s raw rows (untyped, since a typed read would stop at the first bad value) and runs `sdmxlib.polars.validation_report` on each batch. The per-batch reports are then summed, so memory stays bounded. Rows are ordered by component in DSD order, and by value within each component.

**Tests:**
- A differential test against `validation_report` over the whole raw frame, at `chunk_rows` 1, 2 and 100k. At 1 and 2, `ZZ` is split across batches.
- The empty report keeps its schema.
- A query with no structure is refused.
- Sabotage check: with the sum across batches removed, the split cases fail.

`sdmxlib.polars` is imported at the top of the module; there is no cycle and no suppression.

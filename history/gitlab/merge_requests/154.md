## What's here
- `msgspec` added to baseline runtime deps (500 KB, zero deps).
- **`formats/sdmx_json/_dto.py`** — the cross-cutting wire Structs (`Annotation`, `Link`, `Meta`, `Sender`), the `InternationalString ↔ (name, names)` helpers (`emit_istr`/`ingest_istr`, sharing the model's backing map on the hot path via `as_dict(copy=False)`), the annotation ↔ model converters, and a shared `Encoder`.
- The module docstring **codifies the conventions** the per-artefact DTOs must follow:
  - `omit_defaults=True` on every wire Struct;
  - **always-present fields (`id`/`agencyID`/`version`) are REQUIRED (no default)** — the trap the codelist spike hit, where a defaulted `version="1.0"` silently vanished under `omit_defaults`;
  - unknown fields ignored on decode (forward-compat);
  - the istring / annotation split.
- `test_dto.py` locks all of it, including a guard test contrasting a *defaulted* vs *required* field so the `omit_defaults` gotcha can't recur.

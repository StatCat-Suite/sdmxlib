Part of #492, stage 1, installment 1 of 4.

The rules a value alone decides used to run only in `validate()`, which binds only where something calls it, and a store read trusted its rows. They are now **attrs field validators** (`model/_rules.py`). Construction, assignment and `attrs.evolve` all refuse such a value, raising `ValidationError` with the issue path `Class.field`.

## Decisions (from the discussion)
- **Readers fail fast at construction.** `build_each` catches the construction error the way it catches `SdmxConformanceError`, so the artefact is refused and references to it are withdrawn. `parse` turns any other `ValidationError` into `SdmxParseError`, which today means a metadata set. A refusal reason now names the first bad value rather than every one.
- **Tests use attrs' `validators.disabled()`**, wrapped as `tests/support/unchecked.py`. The library gets no bypass API.

## What is checked at construction
Exactly the ids `validate()` checked before, and no more:
- **Every maintainable:**
  - `id`: NCNameIDType for Codelist, ConceptScheme and CategoryScheme, IDType otherwise. `test_xsd_conformance` now derives the model's side from the field validators and compares it to the schemas.
  - `maintainer`: its agency id must be a NestedNCNameIDType.
  - `version`: either grammar (#319).
- **Items and components:** `id` on Code, Concept, Category, DataProvider, HierarchicalCode, a DSD's Dimension, Attribute and Measure, and MetadataAttribute.
- **`Agency` stays in `validate()`:** the same class serves as the dotted maintainer reference, so its id can't carry one validator.

`validate()` keeps the rules that need the whole artefact. The three moved `_check_*` functions and the polars id path are gone. The IM census marks IM-3.2.2.2-3 (version) as `Structural`, and its counts are updated (77 → 74 checks).

## Cost

Retained memory is unchanged, since a validator adds no state to an instance.
- **Calls per row:** the check costs two Python calls a row (the validator, plus one regex match on the valid path). The first version took four; the fast path halved it.
- **Bundle-tier budgets:** each of the bundle tier's per-row budgets rose by two, following #422's precedent so each keeps its margin. The measured `code` 19.14 / 35.33 and `hcode` 36.02 / 36.02 are recorded beside them.
- **Count guard:** `test_rules_count` asserts one regex match per code built, and none on `add` or `get`.

## Breaking
- Building an artefact with an invalid id, agency id or version raises `ValidationError`.
- `DataConstraint`, `AttachmentConstraint`, `Hierarchy`, `HierarchyAssociation`, the four scheme maps and `StructureMap` no longer default `id` to `""` or `maintainer` to an empty agency.

## Evidence
- `just ci` is green: 11,044 unit, 125 integration, docs, and the bundle tier's assertions. pyrefly reports 0 errors, and no new suppressions were added.
- **Sabotage:**
  - Each new guard fails when its fix is removed: a validator dropped from `Dataflow.id`, `Categorisation` switched to NCName, the `build_each` catch removed, the `parse` catch removed, and an id checked twice.
  - The default-construction reflection test now gives a maintainable a minimal identity before skipping it. The suite's skips went from 100 to 84.

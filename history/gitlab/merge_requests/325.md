`is_final` and `uri` were written correctly for every artefact and read
back as their defaults for seven of them — Categorisation,
CategoryScheme, ConceptScheme, Dataflow, HierarchyAssociation,
ProvisionAgreement, RepresentationMap. `_put_spine` is shared; the
readers are not. Nineteen of them each wrote the same seven kwargs by
hand, and seven wrote five.

So the fix is not the seven readers. `_spine_kwargs(meta)` returns the
lot as a TypedDict — typed, so each value is still checked against the
parameter it lands on — and all nineteen unpack it. A field added to
`MaintainableArtefact` now belongs in the DDL and in that dict, and
reaches every reader from the second.

`HierarchyAssociation` genuinely has no `is_final`, and that is not an
oversight: it exists only in SDMX 3.0/3.1 and 3.0 removed isFinal from
every maintainable — the fact `formats.gaps` already declares on the
writing side. It gets the narrower helper, and the reason is written
where the next reader will look.

The lazy proxies took `agency=` where every artefact takes
`maintainer=`; renamed, so the same spine fits them too.

Two guards, at different distances. The derived round-trip guard
(#316) covers the fields, and its eight KNOWN_LOSSES entries are
deleted here — it fails on an unexpected pass, so it confirmed the fix
rather than being told about it. The new static guard covers the
*shape*: constructing a maintainable with `id=` and no `**_spine_*`
fails immediately, where the round-trip guard would only notice once
someone set that field in a fixture. Checked by hand-writing one back.

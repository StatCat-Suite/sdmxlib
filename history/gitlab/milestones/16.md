# Milestone %16: Typing hygiene: enforce the Any rule the docs already claim

| | |
| --- | --- |
| State | closed |
| Opened | 2026-08-09 |
| Due | — |

CLAUDE.md states that `src/` carries **zero `Any`-annotated parameters or locals**, and that an `Any` parameter anywhere is a finding. `ANN401` enforces that — for bare annotations.

It does not look inside generic arguments. `def f(x: Any)` is a finding; `def f(x: dict[str, Any])` is not. An audit after %13/%14/%15 found **171 `Any` occurrences in `src/`, 112 of them inside generic arguments** — so the rule everyone believes is enforced covers about 4 of 171 sites.

The audit also found two ruff `warning:` lines that had survived an entire milestone of work, because warnings do not fail the gate and get filtered out of check output as noise.

This milestone closes the enforcement gap first, then reduces the 112 by category. The order matters: without the guard, any cleanup silently refills.

**Baseline at milestone open:** 171 `Any` in `src/` — 112 generic args (`list[Any]` ×39, `SdmxUrn[Any]` ×25, `Ref[Any]` ×16, `dict[str, Any]` ×16), 24 imports, 18 comments, 4 returns (2 legitimately `# noqa: ANN401`), 13 other.

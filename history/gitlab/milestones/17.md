# Milestone %17: Query DSL: a second backend, and the evidence the first one lacks

| | |
| --- | --- |
| State | closed |
| Opened | 2026-08-14 |
| Due | — |

The path language ships over DuckDB (#306, !302). This milestone is what it does not yet have: a second backend to prove the design's central claim, mutation evidence for the compiler, and the surface gaps that were documented rather than closed.

The claim under test is #306's own: **where a query runs is a property of the backend rather than of the language.** Only one backend compiles it, so that claim is currently unexercised.

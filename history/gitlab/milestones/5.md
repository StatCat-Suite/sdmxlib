| | |

Follow-up coverage work surfaced by the XSD validation audit (post-MR !59). Each item closes a specific gap between what the SDMX-ML XSDs allow and what our fixtures / writer / reader actually exercise.

Severity tiers:

**High**
- StructureSet 3.0 split — 3.0 writer currently drops StructureSets on the floor; split into per-kind containers (CodelistMaps, ConceptSchemeMaps, etc.).
- MetadataStructure / Metadataflow (3.0) — writer + model exist, no fixture exercises them.
- HierarchicalCodelist — writer exists, no fixture exercises it.

**Medium**
- Annotations on non-DSD maintainables — only DataStructure has annotations in any fixture.
- AttachmentConstraint (2.1) and DataConstraint role=Forbidden (3.0).
- Attribute attachment levels — Group / Dimension / DataSet untested.
- Contact multi-field — Telephone / Fax / URI / x400 untested.

**Low**
- Multi-language tag bias — only en/fr appear; add de/es/region-coded.
- ReferencePeriod / ReleaseCalendar on constraints — writer handles them; no fixture exercises them.

# Milestone %11: Wire conformance: no artefact serialises to an invalid document

| | |
| --- | --- |
| State | closed |
| Opened | 2026-08-06 |
| Due | — |

Every artefact sdmxlib can build must either serialise to a schema-valid document or be refused with a reason. Today 24 (artefact, format) pairs silently emit invalid output.

Grounded in measurement, not audit-by-eye: the vendored XSDs state seven classes of constraint, and `tests/support/xsd_facts` extracts three of them. Seven of the ten conformance defects found in milestone 10 came from the four it does not extract — minOccurs, use=required, use=prohibited, xs:unique — and every one was found the slow way, by generating an artefact and watching a schema reject it.

This milestone inverts the remaining four, the same move that turned enumerations and pattern facets from 'discover by failing' into a 0.05 s direct check.

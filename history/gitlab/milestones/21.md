# Milestone %21: Conformance evidence: what the green checks do not prove

| | |
| --- | --- |
| State | closed |
| Opened | 2026-10-15 |
| Due | — |

Milestone 20 made the model 3.x-native and added schema-derived censuses, so the schema-to-model direction is checked mechanically. This milestone covers what those checks still cannot see:

- information-model rules that no XSD expresses;
- interoperability for constructs no registry serves;
- SDMX-ML attributes and containers read open-world;
- guards that have never been shown to fail;
- message types outside the structure census.

The aim is that every green check is evidence, not just reassurance.

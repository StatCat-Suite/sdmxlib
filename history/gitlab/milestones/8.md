# Milestone %8: SDMX-JSON: migrate dict+orjson → typed msgspec Structs

| | |
| --- | --- |
| State | closed |
| Opened | 2026-07-22 |
| Due | — |

Replace orjson with msgspec across the entire SDMX-JSON layer (structure, metadata, data), moving from hand-built `dict[str, Any]` + orjson to typed `msgspec.Struct` DTOs used both directions (encode on write, typed decode on read). Goal: remove orjson entirely.

Motivation (validated by the codelist spike): typed Struct DTOs replace `dict[str, Any]` navigation with schema-as-types, and are ~20-25% faster on BOTH serialize and parse. msgspec is a 500 KB zero-dependency compiled extension (footprint ~2x orjson, negligible next to lxml/duckdb/polars).

Sequence is risk-ordered: foundation → de-risk the data plane (numpy/streaming — the only real blocker to full removal) → migrate the proven structure/metadata paths → migrate data → remove orjson. Every issue leaves the build green, is independently mergeable, and is gated by output-parity + schema-validation + strictness tests.

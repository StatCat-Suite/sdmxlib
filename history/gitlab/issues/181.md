Milestone: SDMX-JSON dict+orjson → msgspec. Replace the dict-navigating structure reader with `msgspec.json.decode(data, type=StructureMessageDTO)` → ingest DTOs → attrs model. This delivers the typed-read win (no more `doc[\"data\",\"codelists\",i].get(...)`) and ~20% faster parse.

## Scope
- `parse()` structure path decodes straight into the DTO Structs from #180 then ingests each DTO → attrs artefact.
- Remove the dict-navigation in `reader.py` (structure path).

## Test gates
- Existing reader roundtrip tests pass; **parsed-model parity** vs the current parser (same attrs graph).
- **Strictness audit** — the critical risk: EVERY real SDMX-JSON structure fixture in the repo decodes without `ValidationError`. If a real producer's payload deviates, widen the DTO (Optional / union / `msgspec.Raw` for un-modeled subtrees) rather than falling back to dict navigation. Document any deviations found.
- Round-trip `serialize(parse(x)) == x`-shaped tests across the fixture corpus.

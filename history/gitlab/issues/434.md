## Summary

A 2.1 `HierarchicalCodelist` written in the `CodelistAliasRef` + `CodeID` form loses every code on read, and every writer then emits invalid output.

Found by the registry sweep (!516): OECD's 2.1 HCLs use this form throughout: **8,297** `HierarchicalCode`s lost, 212 HCLs; e.g. `OECD.CFE.EDS:HCL_AGE(1.0)`.

## Repro (passes the 2.1 XSD)

```xml
<str:HierarchicalCodelist id="HCL_AGE" agencyID="OECD.CFE.EDS" version="1.0" isFinal="true">
 <com:Name xml:lang="en">HCL age</com:Name>
 <str:IncludedCodelist alias="CL_AGE@OECD@11">
  <Ref id="CL_AGE" version="1.1" agencyID="OECD" package="codelist" class="Codelist"/>
 </str:IncludedCodelist>
 <str:Hierarchy id="H" leveled="false"><com:Name xml:lang="en">H</com:Name>
  <str:HierarchicalCode id="_T">
   <str:CodelistAliasRef>CL_AGE@OECD@11</str:CodelistAliasRef>
   <str:CodeID><Ref id="_T"/></str:CodeID>
  </str:HierarchicalCode></str:Hierarchy>
</str:HierarchicalCodelist>
```

Read: the node's `code` is `None`. Written: `<str:HierarchicalCode id="_T"/>` with no `Code` and no `IncludedCodelist`: invalid in 2.1 ("Expected (Annotations, Code, CodelistAliasRef)") and 3.0.

## Root cause (no model change needed)

- `sdmx_ml21/reader.py:776-808`: the `CodeID` fallback builds a URN only when the `Ref` has `agencyID` + `maintainableParentID` + `id`. In the alias form it has only `id`. `CodelistAliasRef` is never read, and `IncludedCodelist@alias` is discarded (`:945-948`). `HierarchicalCode.code: Ref[Code]` already exists.
- No writer emits `IncludedCodelist`, and storage does not persist `included_codelists` (1 → 0 after a store round trip).
- The 2.1 writer skips `<Code>` when `code is None` (`writer.py:635-637`), producing an invalid node rather than refusing.
- The HCL reader never passes `is_final` (`reader.py:936-951`), so `isFinal="true"` is dropped.

## Fix direction

Build `{alias: IncludedCodelist ref}` per HCL and resolve `CodelistAliasRef` + `CodeID/@id` into a full `Code` URN. Emit `IncludedCodelist` on write and persist it. Read `is_final`. Refuse a node with no code rather than write it. Relates to #421's hierarchy row, which will convert HCLs on ingest and needs this read to be right first.

Sibling of #207 (rule 4), and the concrete case that motivated it. Small and self-contained; #207 is the general rule, this is the one place we need it now.

## The situation

`Ref` is `@define` (mutable), and its docstring **documents** that the registry resolves refs in place:

```
reg.add(cl_freq)
ref.resolved   # True (if interned through registry)
```

So resolution-by-registry is part of `Ref`'s *contract*. It is not part of its *public API*: read access exists (`resolved`, `__call__`), the write side does not. Six sites therefore reach in directly:

```
model/in_memory_registry.py:94,203,241,242
local/registry.py:900,933
```

```python
canonical._resolved = artefact   # noqa: SLF001
```

## Why not just make it public

Because *who* may resolve a Ref is the invariant. Resolution is supposed to flow through the registry so every holder of a URN converges on one canonical object. A public `ref.resolve(obj)` would advertise, on every `Ref` a user holds, exactly the call that de-canonicalises the graph.

A method also cannot be hidden: `__all__` governs module-level names, not attributes of an exported class. `Ref` is public, so any method on it is reachable.

## Proposal — a package-internal seam

A plainly-named function in a private module, per #207 rule 4 and pydantic's `_internal/` pattern:

```python
# model/_interning.py  (private module, plain name)

def intern_resolution(ref: Ref[T], obj: T) -> None:
    """Attach a resolved artefact to *ref*.

    Package-internal. Resolution must flow through a registry so that all
    holders of a URN converge on one canonical object; calling this from
    outside the registry layer breaks that invariant. Not exported.
    """
    ref._resolved = obj  # noqa: SLF001 — the one sanctioned reach-in; see module docstring
```

The registries call it. Six suppressions become **one**, and that one stops being noise: it marks the seam, in a module whose whole purpose is to be that seam.

## Why this is better than the alternatives

* **vs. status quo (6 line noqas)** — the coupling is invisible; nothing says the registry owns resolution, and nothing stops a seventh site appearing.
* **vs. a public `Ref.resolve()`** — zero suppressions, but it publishes the invariant-breaking call on every Ref.
* **vs. a per-file ignore** — silences future genuine violations in files that legitimately have some.

The suppression count is nearly a wash. The difference is what each option *says*.

## Note on ordering

If #207 rule 5 is adopted (drop SLF001), the noqa disappears and this becomes purely an API-design change — still worth doing, because the value is naming the seam, not silencing the lint. The two are independent.

## Acceptance

* `intern_resolution` in a private module with a docstring naming the invariant and the intended callers.
* The 6 sites call it; suppressions drop to 1 (or 0 under rule 5).
* Not present in `sdmxlib.__all__`.
* `just ci` clean.

## Size

Small — one new module, six call sites.

## Comments

### 2026-08-05

Done in !200 — the first application of CLAUDE.md rule 4.

**Half this issue's premise was wrong, and it was mine.** I listed six sites reaching into `Ref._resolved` as evidence the write API was missing. Only **three are writes**. The other three were *reads* where `Ref.resolved` — a public property — already existed:

```python
if ref._resolved is not None:   ->  if ref.resolved:
if value._resolved is None:     ->  if not value.resolved:
```

Those needed no seam at all; they were code not using the API it already had. Worth recording, because "six sites reach in" was the number that made the case look compelling.

**The seam carries zero suppressions.** This issue predicted one `# noqa: SLF001` replacing six. !199 retired SLF001, so the write is ordinary code — leaving the value purely as API design, which is what the issue argued was the real benefit anyway.

**Privacy verified rather than assumed:**

```
intern_resolution in sdmxlib.__all__  -> False
sdmxlib.intern_resolution reachable   -> False
importable by path (intended)         -> True
```

Three tests, the substantive one being that resolution propagates to a `Ref` taken *before* the artefact was added — the invariant a public `ref.resolve()` would let callers break. Checked non-vacuous: False -> True, same object identity.

Closing.

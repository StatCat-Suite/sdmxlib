Implement structural validation for SDMX artefacts.

## Motivation

```python
issues = sl.validate(dsd)
for issue in issues:
    print(f"{issue.severity}: {issue.path} — {issue.message}")

ref_issues = sl.validate_references(msg)
for issue in ref_issues:
    print(f"BROKEN: {issue.source} → {issue.target_urn}")
```

Validation is explicit and separate from construction — domain objects can be built in any intermediate state without errors.

## Types

```python
@dataclass(frozen=True)
class ValidationIssue:
    path: str        # e.g. "dimensions[FREQ].codelist.urn"
    message: str
    severity: str    # "error" | "warning"

@dataclass(frozen=True)
class ReferenceIssue:
    source: str      # e.g. "DataStructure:ESTAT:CPI.dimensions[FREQ].codelist"
    target_urn: str
    message: str
```

## `validate(artefact, *, strict=False)`

Per-artefact checks:
- `id` matches `[A-Za-z0-9_-]+`
- `agency_id` matches `[A-Za-z0-9._-]+`
- `version` matches semver-like pattern
- Code id uniqueness within a `Codelist`
- Dimension `position` values form a contiguous 1-based sequence
- `Ref` URN validity

If `strict=True`, raises `ValueError` on the first issue.

## `validate_references(msg)`

Walks all artefacts in `StructureMessage` via `dataclasses.fields()`. For each `Ref` field, checks the URN resolves to an artefact present in the message. Returns `list[ReferenceIssue]` for any broken references.

## Implementation

New file `model/validation.py` (stdlib only). Uses `dataclasses.fields()` for generic field walking.

## Tests

New `tests/unit/test_validation.py`:
- Valid artefact → no issues
- Bad `id` format → error reported
- Duplicate code ids → error
- Position gap in dimensions → error
- All refs resolved → no issues
- Missing codelist → `ReferenceIssue`

# Issue #14: feat(model): __post_init__ coercion on all domain model classes

| | |
| --- | --- |
| State | closed |
| Opened | 2026-03-30 |
| Closed | 2026-03-30 |
| Milestone | %1 Construction, Coercion & Validation |

Add `__post_init__` coercion to all domain model classes so construction accepts convenient Python types alongside the strict stored types.

## Motivation

Currently building artefacts requires wrapping every value:

```python
Codelist(id="CL_FREQ", agency_id="SDMX",
    name=InternationalString(en="Frequency"),
    codes=ItemList([Code(id="A", name=InternationalString(en="Annual"))]))
```

After this issue:

```python
Codelist(id="CL_FREQ", agency_id="SDMX",
    name={"en": "Frequency"},
    codes=[Code(id="A", name={"en": "Annual"})])
```

## Coercion rules

| Field type | Accepts | Stored as |
|---|---|---|
| `InternationalString` | `dict[str, str]` | `InternationalString(**dict)` |
| `ItemList[T]` | `list[T]` | `ItemList(list)` |
| `ArtefactList[T]` | `list[T]` | `ArtefactList(list)` |
| `Ref[T]` (T: Maintainable) | `T` instance | `Ref.to(instance)` |
| `Annotations` | `list[Annotation]` | `Annotations(list)` |
| `Representation` | (inferred) | `Enumeration(urn=codelist.urn)` if codelist set and representation is None |

## Files to modify

## Implementation pattern

All coercion uses `object.__setattr__` (required for `frozen=True, slots=True`). Cross-module `isinstance` checks use local imports inside `__post_init__` to avoid circular imports.

```python
def __post_init__(self) -> None:
    if isinstance(self.name, dict):
        object.__setattr__(self, "name", InternationalString(**self.name))
    if isinstance(self.codes, list):
        object.__setattr__(self, "codes", ItemList(self.codes))
```

Field annotations are widened to the union of strict + coercible types.

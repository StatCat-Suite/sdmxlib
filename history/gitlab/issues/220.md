# Issue #220: parse() misroutes structure messages containing 'GenericMetadata' — silent data loss

| | |
| --- | --- |
| State | closed |
| Opened | 2026-08-06 |
| Closed | 2026-08-06 |
| Labels | `bug` |

`parse()` decides whether a payload is a StructureMessage or a MetadataMessage by **substring-searching the first few KB of the raw bytes**. Any structure message whose *content* happens to contain one of the sentinel tokens is misrouted — and in three of five cases that means **silent data loss**, not an error.

## Reproduction

A codelist whose name mentions the token. Nothing contrived: a codelist *of SDMX message types*, a concept named `GenericMetadata`, or annotation text citing the metadata schema would all do it.

```python
cl = Codelist(id="CL_MSGTYPE", maintainer="A", version="1.0",
              name=InternationalString(en="Message types incl GenericMetadata"), codes=[...])
blob = sdmx_ml30.writer.write(StructureMessage(codelists=[cl]))
parse(blob)
# -> MetadataMessage(metadata_sets=[])   the codelist is gone, no error
```

| Format | Token in content | Result |
| --- | --- | --- |
| SDMX-ML 3.0 | `GenericMetadata` | **`MetadataMessage`, empty — codelist silently dropped** |
| SDMX-JSON | `metadata-schema` | **`MetadataMessage`, empty — codelist silently dropped** |
| SDMX-ML 2.1 | `GenericMetadata` | `ValueError: Metadata messages are not supported for '2.1'` |
| SDMX-ML 3.1 | `GenericMetadata` | `ValueError: Metadata messages are not supported for '3.1'` |

The two `ValueError`s are wrong but loud. The two silent cases are the bug that matters: a caller gets an empty message back and no indication anything was lost.

## Cause

`formats/__init__.py::_detect_message_kind`:

```python
# XML: root element wins.  <- the comment says root element
chunk = data[:4096].decode("utf-8", errors="replace")
if "GenericMetadata" in chunk:      # <- but this is a substring search
    return "metadata"
return "structure"
```

The comment states the correct rule — *the root element decides* — and the code does not implement it. The JSON branch has the same shape:

```python
chunk = data[:4096]
if _METADATA_JSON_SCHEMA.encode("utf-8") in chunk: return "metadata"
if b"metadata-schema" in chunk:                     return "metadata"
if b'"metadataSets"' in chunk:                      return "metadata"
```

`b'"metadataSets"'` is quote-anchored so it is harder to trip; `b"metadata-schema"` is a bare token and trips easily.

There is a second, milder instance in `_detect_version`, which substring-matches namespace URIs in the first 2048 bytes. Those are long and distinctive, and they legitimately appear in the root element, so the risk is much lower — but the same fix applies.

## Fix

**XML** — read the actual root element. `etree.iterparse` with `events=("start",)` stops at the first element, so this is cheap and does not depend on a byte window:

```python
for _event, el in etree.iterparse(BytesIO(data), events=("start",)):
    return etree.QName(el).localname   # and .namespace for the version
```

That fixes `_detect_message_kind` and `_detect_version` together, and removes the 2048/4096-byte truncation limit as a class of bug.

**JSON** — discriminate on the *value* of `$schema` rather than its presence anywhere in the document. A small `msgspec.Struct` probe is the natural fit now that the envelopes are typed (#200).

## Test gates

- A structure message containing each sentinel token round-trips as a `StructureMessage` in all four formats.
- A real metadata message is still detected as metadata in every supported format.
- A property test: for any generated artefact, `parse(write(msg))` yields a message of the same kind. This is the check that would have caught it.
- No reliance on a fixed byte prefix — a token appearing after 4096 bytes must not change the verdict either.

## Provenance

Found while building the #216 round-trip properties. A generated codelist failed to round-trip through SDMX-ML 3.1; the specific Hypothesis example did not reproduce afterwards, but reading `_detect_message_kind` to explain it exposed the mechanism, which then reproduced deterministically in all four formats.

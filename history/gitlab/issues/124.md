## Why

A contiguous block at lines **161–227** is entirely uncovered. Reading the source, this is the SKOS-style hierarchy traversal surface on \`Codelist\`:

- \`narrower(code_id)\` — direct children
- \`broader(code_id)\` — direct parent
- \`narrower_transitive(code_id, depth=...)\` — all descendants, optionally bounded
- \`broader_transitive(code_id, depth=...)\` — all ancestors, optionally bounded
- \`depth_of(code_id)\` — root-distance lookup
- Likely also \`roots()\` (parents-of-no-one helper above this range)

These are core Codelist navigation methods — a user holding a Codelist with parent-id chains will call them. They have no tests.

## Proposed work

Tests against a small parent-chained fixture covering:

- \`narrower\` / \`broader\` happy + missing-id + roots/leaves
- \`narrower_transitive\` with no depth, depth=1, depth=∞
- \`broader_transitive\` with no depth, depth=1
- \`depth_of\` for root (=0), leaf, missing id (KeyError)
- Cycle-breaking behaviour if any (looks like \`seen\` set is used in \`narrower_transitive\` — worth confirming a synthetic cycle doesn't loop forever)

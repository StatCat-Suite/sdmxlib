# Issue #36: feat: add typed Urn class for SDMX URN identifiers

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-15 |
| Closed | 2026-05-02 |

## Summary

sdmxlib currently represents SDMX URNs as plain strings (`str`) throughout the API — in `LocalRegistry.get()`, on artefact fields like `Codelist.urn`, and in storage queries. This makes it easy to pass arbitrary strings where a URN is expected, losing both validation and IDE discoverability.

## Proposal

Add a `Urn` (or `SdmxUrn`) class that:
- Validates the URN format on construction (e.g. `urn:sdmx:org.sdmx.infomodel.*`)
- Exposes parsed components as properties: `agency`, `artefact_class`, `id`, `version`
- Works as a dict key and in sets (hashable, equality by value)
- Has `__str__` returning the raw URN string
- Is accepted anywhere a URN string is currently accepted (via `str | Urn` union or `__str__` protocol)

## Motivation

Downstream libraries (e.g. pinax) use URNs as foreign keys to reference sdmxlib artefacts. A typed URN would:
1. Prevent passing arbitrary strings where a URN is expected
2. Enable IDE autocompletion on parsed components
3. Make the API more self-documenting

## Compatibility

This can be introduced incrementally — existing `str` parameters gain `str | Urn` union types, keeping backward compatibility.

## Comments

### 2026-05-02

Closed as already shipped. SdmxUrn[T] in src/sdmxlib/model/urn.py (exported as sl.SdmxUrn) satisfies every acceptance criterion:

- Validates on construction (parse() regex; make() validates SDMX 2.1/3.0 formal IDType / NestedIDType against agency and id; allows e.g. agency 'IMF.STAT', 'A.B.C').
- Exposes parsed components: agency, artefact_class, id, version — plus bonus package and item_id.
- Hashable + equality by value via @frozen attrs (covered by test_equality_and_hashing).
- __str__ round-trips back to the raw URN string (covered by 69 tests in tests/unit/test_urn.py).
- Used as the typed input throughout the API: Registry.get(urn: SdmxUrn[T]) -> T | None, so callers get T propagated by the type checker.

Beyond the proposal:

- Phantom type parameter SdmxUrn[T] threads the artefact type through reg.get / session.get, so 'cl = reg.get(Codelist.urn(...))' types as Codelist | None without explicit cast.
- MaintainableArtefact.urn(agency=, id=, version=) classmethod on every artefact builds typed URNs without callers writing the package/class strings by hand.
- parse_rest_ref(s) classmethod (v0.18.0) symmetric with urn() for SDMX REST 'AGENCY,ID,VERSION' refs.

The proposal mentioned str | Urn union for backwards compatibility — we took a stronger position: the API requires SdmxUrn[T] throughout, no str union. Cleaner, and the type checker does more work for callers.

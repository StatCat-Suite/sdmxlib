# Issue #192: [S1] _maint_fields: Protocol param + TypedDict return — removes 21 type-ignores

| | |

The single largest suppression cluster in the codebase: **21 of the 47 `type: ignore`s in `src/`** (45%) trace to one signature in `formats/sdmx_json/_structure_dto.py`.

```python
def _maint_fields(m: object) -> dict[str, object]:
    ...
    "id": m.id,          # type: ignore[attr-defined]   ×3
```
```python
return CodelistJson(**_maint_fields(cl), ...)  # type: ignore[arg-type]   ×18
```

Two defects, one root cause:

* `m: object` → `m.id` / `m.agency_id` / `m.version` are unreadable (3 ignores). The other fields already use `getattr(m, ..., None)`, so the signature is inconsistent with itself.
* `-> dict[str, object]` → every `**` splat into a typed `msgspec.Struct` fails all 11 field assignments at once (18 ignores).

**Evidence.** Stripping these 21 comments and running `basedpyright src` produces 200+ errors from these call sites alone — one splat fans out to 11–12 errors. They are silencing real, checkable structure.

## Fix

* Param: a Protocol with `id` / `agency_id` / `version` read-only properties. `model/ref.py:SupportsUrn` already has exactly that shape — reuse it or add a sibling if the optional fields (`name`, `description`, `valid_from`, `valid_to`, `is_final`, `annotations`) should be in the contract rather than `getattr`-probed.
* Return: a `TypedDict` (`MaintFields`) with the 11 known keys. `CLAUDE.md` already prescribes this: *"Prefer a TypedDict for known-shape payloads."*

## Verified before filing

A standalone probe — `Protocol` param, `TypedDict` return, `**splat` into a `msgspec.Struct` — type-checks at **0 findings under both basedpyright and pyrefly**. The pattern works; this is not speculative.

## Acceptance

* All 21 suppressions in `_structure_dto.py` deleted, none replaced.
* `just check` clean; SDMX-JSON round-trip tests green.

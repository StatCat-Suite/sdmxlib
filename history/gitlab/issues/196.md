# Issue #196: [S2] httpx pass-through kwargs: **kwargs: Any + allow-star-arg-any — 1 ignore hiding 17 errors

| | |
| --- | --- |
| State | closed |
| Opened | 2026-08-04 |
| Closed | 2026-08-05 |
| Milestone | %9 Suppression audit: fix the defect, not the symptom |
| Labels | `type::refactor`, `typing` |

The worst suppression-to-error ratio in the codebase. `api/client.py`:

```python
def __init__(self, ..., **httpx_kwargs: object) -> None:
    self._client = httpx.Client(
        headers=default_headers,
        timeout=timeout,
        **httpx_kwargs,          # type: ignore[arg-type]
    )
```

Stripping that one comment yields **17 errors** — `auth`, `params`, `cookies`, `verify`, `cert`, `trust_env`, `http1`, `http2`, `proxy`, `mounts`, `follow_redirects`, `limits`, `max_redirects`, `event_hooks`, `base_url`, `transport`, `default_encoding` — because `object` is not assignable to any of httpx's parameter types.

Forwarding arbitrary caller kwargs to a third-party constructor is a legitimate gradual-typing boundary. The problem is the shape: `object` is *provably* wrong for every one of those parameters, so the annotation guarantees an error that then has to be silenced blanket-style.

## Fix

`Any` is the honest annotation for a pass-through star-kwarg, and ruff has an option for exactly this case:

```python
def __init__(self, ..., **httpx_kwargs: Any) -> None:
```
```toml
[lint.flake8-annotations]
allow-star-arg-any = true
```

## Verified before filing

`allow-star-arg-any = true` exempts `**kw: Any` while **still flagging** an ordinary `x: Any` parameter — so the ANN401 boundary lint added in !184 keeps its teeth everywhere that matters.

Note this changes the earlier finding recorded in `ruff.toml`: the option measured zero effect at the time precisely *because* this site was annotated `object` + ignore rather than `Any`. Update that comment when fixing.

## Acceptance

* `**httpx_kwargs: Any`, `allow-star-arg-any = true`, ignore deleted.
* `just check` clean; ANN401 still fires on a test `x: Any` parameter (guard against over-broad config).

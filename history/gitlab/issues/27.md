# Issue #27: Replace agency_id: str with maintainer: Agency on MaintainableArtefact

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-01 |
| Closed | 2026-04-01 |

## Problem

Every maintainable artefact (Codelist, DataStructure, etc.) stores `agency_id: str` — a bare string that discards all Agency metadata (name, description, contacts, hierarchy) present in the source.

## Solution

Replace `agency_id: str` with `maintainer: Agency | str` on all 11 maintainable artefact classes. `__post_init__` normalises a plain string to `Agency(id=str)`. Add `agency_id` as a `@property` returning `self.maintainer.id` for backwards compatibility with internal code and the `Maintainable` protocol.

Readers populate `maintainer` opportunistically: if an `AgencyScheme` was parsed in the same response, the richer `Agency` object is reused; otherwise `Agency(id=agencyID)` is created.

## Affected areas

- 11 model classes (all `MaintainableArtefact` subclasses)
- `Maintainable` protocol in `collections.py`
- `Ref.to()` in `ref.py`
- All three format readers and writers (SDMX-ML 2.1, 3.0, JSON)
- `session.py`, `validation.py`
- ~106 test occurrences

## Precedent

This matches sdmx1's approach: `maintainer: Agency | None = None` with opportunistic parse-stack reuse.

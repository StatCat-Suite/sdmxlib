3.0 writer at src/sdmxlib/formats/sdmx_ml30/writer.py explicitly drops StructureSets in the 3.0 output path. SDMX 3.0 replaced the unified StructureSets container with per-kind containers: CodelistMaps, ConceptSchemeMaps, CategorySchemeMaps, DataStructureMaps, DataflowMaps. Real ECB mapping documents would silently lose all maps in 3.0 output.

Fix: split a StructureSet into the matching 3.0 top-level containers; round-trip via the existing model.StructureSet shape (so 2.1 round-trip stays untouched and 3.0 round-trip preserves maps). Add a 3.0 fixture exercising at least CodelistMap + ConceptSchemeMap.

Split from #170 (part 1 of 3). This is the genuinely mechanical slice: every site here has a **concrete type or union already in `model/`**, so no Protocol design is needed. #170 framed all its sites as "a textbook Protocol case" — for these nine that is simply the wrong tool.

## Sites

| Site | `Any` param | Correct type |
| --- | --- | --- |
| `storage/writers.py:891` | `_flatten_hcodes(nodes)` | `Sequence[HierarchicalCode]` |
| `storage/writers.py:1003` | `_flatten_categories(categories)` | `Sequence[Category]` (also the `Any` in its `result` tuple) |
| `storage/writers.py:1247` | `_flatten_metadata_attributes(attributes)` | `Sequence[MetadataAttribute]` |
| `storage/writers.py:1382` | `_collect_reported_values(attributes)` | `Sequence[ReportedAttribute]` |

| `formats/sdmx_ml30/writer.py:206` | `_write_representation(representation)` | `Facet \| AnyRef \| None` |
| `formats/sdmx_ml31/writer.py:208` | `_write_representation(representation)` | same |
| `formats/sdmx_ml/_common.py:1041` | `_write_id_pair_maps(pairs)` | `Sequence[ItemMap \| ComponentMap \| ValueMap]` |
| `storage/readers.py:327` | `_to_float(v)` | `object` — duckdb row value, narrowed internally; CLAUDE.md's "`object` by default" litmus |

The four `_flatten_*` / `_collect_*` helpers are the clearest: each already declares its **element** type in the `result: list[...]` parameter right below the `Any`, so the type is sitting in the signature already.

`_write_representation` is the sharpest case — the body `isinstance`-checks `Facet` then `Ref` on the next two lines. The `Any` disables checking and buys nothing.

## Why this is worth doing even though nothing forces it

ANN401 is per-file-exempted for `formats/**`, `storage/**`, `local/**` (`ruff.toml:115-121`) by deliberate design — this is the untyped shell. So there is **no gate** behind this issue; it is voluntary. The argument for doing it anyway is that these particular sites aren't shell-boundary `Any` (raw msgspec/lxml/duckdb input) — they receive **already-parsed domain objects**, so the shell exemption isn't what's justifying them. They're just untyped.

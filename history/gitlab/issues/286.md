25 occurrences. **This one must not be swept**, and CLAUDE.md already says why:

> `SdmxUrn`’s `T` is a phantom, so `SdmxUrn[Any]` and `SdmxUrn[object]` give *identical* body-checking. Use **`SdmxUrn[object]`** for pure-consumer params (URN only stringified / used as a str key). Keep **`SdmxUrn[Any]`** only where the phantom is recovered downstream — `parse() -> SdmxUrn[Any]` (feeds `Ref.unresolved(urn) -> Ref[T]`, which needs the bivariance) and anything feeding `get[T]`.

So the work is: classify each of the 25 as consumer or recovering, change the consumers, and leave a comment on the ones that stay. A blanket rewrite breaks `parse()` feeding `Ref.unresolved`.

**Tier 1 — safe, model-core.** From the `Any` audit (★5, CALLABLE_SIG).

`to_dict(key: str | Callable[[T], Any]) -> dict[Any, T]`
(`model/collections.py:177,382`) throws away the dict-key type. In the callable
branch it's recoverable.

**Fix:** overloads with a key TypeVar —
```python
@overload
def to_dict(self, key: str = "id") -> dict[str, T]: ...
@overload
def to_dict[K](self, key: Callable[[T], K]) -> dict[K, T]: ...
```
The `getattr`-by-name path stays `dict[str, T]`; the callable path recovers `K`.

**Acceptance:** `lst.to_dict(lambda x: x.id)` infers `dict[str, T]`; `just ci`
green. (Optionally tighten `sort_by`'s key to `SupportsRichComparison` — nice to
have, not required.)
**Risk:** low.

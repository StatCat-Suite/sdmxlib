# Issue #169: [T2] Narrow reader resolution index dict[str, Any] -> dict[str, object]

**Tier 2 — mechanical formats sweep.** From the `Any` audit (largest single
narrowable pattern, ~80 sites).

Every ML/JSON reader helper threads a resolution index `index: dict[str, Any]`
whose values are always parsed SDMX domain objects — never arbitrary. The `Any`
silently poisons every helper that passes `index` through.

**Sites:** `formats/sdmx_ml21/reader.py`, `sdmx_ml30/reader.py`,
`sdmx_ml31/reader.py`, `sdmx_json/reader.py`, `formats/sdmx_ml/_common.py`.

**Fix:** `dict[str, object]` (values are stored + looked up, rarely
attribute-accessed without a cast). If a common base (`Identifiable`/
`Maintainable`) fits, prefer `dict[str, <base>]`.

**Acceptance:** index typed `object`/base; `just ci` + format round-trip/XSD
tests green. A few sites may surface a needed local cast — that's the point.
**Risk:** low but wide.

# Issue #12: feat(model): add Ref.to() classmethod

Add a `Ref.to(obj)` classmethod that creates a resolved `Ref[T]` from a `MaintainableArtefact` instance.

## Motivation

Currently users must build a URN manually and call `Ref.of(urn, obj)`. With `Ref.to()`, passing a bare artefact instance is enough:

```python
cl = Codelist(id="CL_FREQ", agency_id="SDMX", version="1.0", ...)
ref = Ref.to(cl)  # resolved Ref[Codelist]
```

This is also the foundation for coercion in Issue #coercion — when a `Dimension` receives a bare `Codelist` it calls `Ref.to(codelist)` internally.

## Implementation

In `model/ref.py`, add:

```python
@classmethod
def to(cls, obj: T) -> Ref[T]:
    """Create a resolved Ref from a MaintainableArtefact instance."""
    from sdmxlib.model.urn import SdmxUrn
    urn: SdmxUrn[T] = SdmxUrn.make(
        type(obj),
        package=obj._sdmx_package,
        artefact_class=obj._sdmx_class,
        agency=obj.agency_id,
        id=obj.id,
        version=obj.version,
    )
    return cls(urn=urn, _resolved=obj)
```

Use local import inside the method to avoid circular imports. Duck-type the attribute accesses with `# type: ignore[union-attr]`.

## Tests

- `Ref.to(codelist)` returns a resolved `Ref` with correct URN
- `ref()` returns the original object
- Works for `Codelist`, `DataStructure`, `Dataflow`

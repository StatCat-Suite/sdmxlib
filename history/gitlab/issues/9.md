## Overview

Add `sdmxlib/contrib/fastapi/` — a FastAPI integration for exposing SDMX structural metadata via a REST API.

## Spec reference

From `docs/design/sdmxlib_v2_final_spec.md` section 14 (FastAPI Integration) and Phase 6 implementation order.

## Planned scope

- `contrib/fastapi/schemas.py` — Pydantic models mirroring the domain model (Codelist, DataStructure, Dataflow, etc.)
- `contrib/fastapi/router.py` — Example APIRouter with endpoints for browsing artefacts
- Optional dependency: `sdmxlib[fastapi]` pulling in `pydantic` and `fastapi`

## Dependencies

- Core domain model (done)
- No dependency on formats or API layers required

## Notes

- `sdmxlib.model` has zero external deps — the Pydantic bridge lives entirely in `contrib/`
- Defer until there is a concrete use case driving the endpoint design

**Phase 0.** Unblocks the Hypothesis work (#test-5), and is worth doing on its own.

## The measurement

Helper functions defined independently in multiple unit-test files:

| Helper | Files defining it |
| --- | --- |
| `_schema` | 8 |
| `_roundtrip` | 8 |
| `_binding` | 8 |
| `_make_msd` | 6 |
| `_make_dsd` | 6 |
| `_load` | 5 |
| `_dsd` | 5 |
| `_code_urn` | 5 |

Same names, subtly different bodies. `tests/support/` today holds only `xsd.py` and `json_schema.py`; there is no factory module.

This is not just tidiness. Every one of those builders encodes an opinion about what a *valid* artefact looks like, and those opinions have drifted apart. Hypothesis strategies have to encode that opinion **once**, so the divergence has to be resolved first — and resolving it will surface cases where one file's idea of a valid DSD is not another's.

## Scope

- `tests/support/factories.py` — one builder per artefact family (Codelist, ConceptScheme, DataStructure, Dataflow, MSD, MetadataSet, Hierarchy, DataflowBinding), keyword-only, with sensible minimal defaults and explicit knobs for the variations the current call sites need.
- Migrate the ~50 call sites. Where two builders genuinely differ, keep both but name the difference (`make_dsd(with_attribute=True)`), do not paper over it.
- `_roundtrip` / `_schema` are per-format; put them in `tests/support/roundtrip.py` parameterised by format rather than duplicated per module.

## Explicitly not in scope

Changing any assertion. This is a pure refactor of test *setup*; if a test's outcome changes, the builder was wrong and that is a finding to record, not to absorb silently.

## Test gates

- Full suite green with no assertion edits.
- **Duplicate-definition count falls** — 19 families with 3+ definitions, 100 definitions total, measured at the start. This is the metric that tracks the goal.
- ~~Net reduction in `tests/` LOC~~ — **withdrawn**. Shared modules are the right home for the docstrings explaining why a harness is shaped as it is, and a LOC gate pushes toward under-documenting them to move a number. The first pass (!213) removed 143 lines from `tests/unit/` and added 176 in `tests/support/`; that is a good trade, and the gate would have called it a failure.
- No helper name defined in more than one module (re-run the count above).

# Issue #15: feat(model): DataStructure immutable modification helpers

| | |
| --- | --- |
| State | closed |
| Opened | 2026-03-30 |
| Closed | 2026-03-30 |
| Milestone | %1 Construction, Coercion & Validation |

Add `with_dimension()`, `with_added_dimension()`, `with_attribute()`, `with_added_attribute()` to `DataStructure`.

## Motivation

`DataStructure` is frozen. Modifying it requires `dataclasses.replace()` by hand. These helpers make common mutations ergonomic:

```python
updated = dsd.with_dimension(replace(dsd.dimensions["FREQ"], codelist=new_cl))
extended = dsd.with_added_dimension(Dimension(id="REF_AREA", position=2, ...))
```

## Implementation

In `model/datastructure.py`:

```python
from dataclasses import replace

def with_dimension(self, dim: Dimension) -> DataStructure:
    return replace(self, dimensions=[dim if d.id == dim.id else d for d in self.dimensions])

def with_added_dimension(self, dim: Dimension) -> DataStructure:
    return replace(self, dimensions=[*self.dimensions, dim])

def with_attribute(self, attr: Attribute) -> DataStructure:
    return replace(self, attributes=[attr if a.id == attr.id else a for a in self.attributes])

def with_added_attribute(self, attr: Attribute) -> DataStructure:
    return replace(self, attributes=[*self.attributes, attr])
```

With coercion from #14, passing a `list` to `replace()` is fine — `__post_init__` wraps it automatically.

## Tests

- `with_dimension` replaces by id, preserves all other dimensions
- `with_added_dimension` appends, does not mutate original
- Same for attribute variants
- Replacing a non-existent id leaves all dims unchanged (not an error — matches list comprehension semantics)

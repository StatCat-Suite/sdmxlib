Add `ConceptScheme.ref_to(concept_id)` — returns a resolved `Ref[Concept]` pointing to a concept within the scheme.

## Motivation

Building a `Dimension` requires a concept reference. Currently that means constructing a URN by hand. With `ref_to()`:

```python
cs = ConceptScheme(id="CS_COMMON", agency_id="SDMX", version="1.0", concepts=[...])
dim = Dimension(id="FREQ", concept=cs.ref_to("FREQ"), ...)
```

## Implementation

In `model/concept.py`, add to `ConceptScheme`:

```python
def ref_to(self, concept_id: str) -> Ref[Concept]:
    """Build a resolved Ref to a concept within this scheme. Raises KeyError if absent."""
    from sdmxlib.model.ref import Ref
    from sdmxlib.model.urn import SdmxUrn
    concept = self.concepts[concept_id]
    urn = SdmxUrn.make(
        Concept,
        package="conceptscheme",
        artefact_class="Concept",
        agency=self.agency_id,
        id=self.id,
        version=self.version,
        item_id=concept_id,
    )
    return Ref.of(urn, concept)
```

## Tests

- Returns a resolved `Ref` with correct item URN
- `ref()` returns the `Concept` object
- Raises `KeyError` for unknown concept id

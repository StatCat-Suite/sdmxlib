# Issue #396: Query.collect() is declared list[object], so every collected artefact needs re-narrowing

| | |
| --- | --- |
| State | closed |
| Opened | 2026-09-07 |
| Closed | 2026-09-07 |

Found while typing `tests/bench` for #370.

## The shape

`Query[R: RowKind]`'s object-building terminals all erase what they return:

```python
def collect(self, *, annotations: bool = True) -> list[object]: ...
def first(self) -> object | None: ...
def one(self) -> object: ...
def one_or_none(self) -> object | None: ...
```

So this does not type-check, though it is correct at runtime:

```python
nodes = reg.query(q.hcode).filter(...).collect()
nodes[0].level          # error: Cannot access attribute "level" for class "object"
```

`ids()`, `count()`, `frame()`, `select()` and `preview()` are all typed fine.
It is specifically the terminals that build domain objects.

## Why it is not simply `list[R]`

`R` is the **row kind** — a pure phantom marking the relation so a predicate
built for one root cannot be handed to a query over another (see `RowKind`'s
docstring). The collected *artefact* is a different type, and the mapping is
per-root:

| root | `collect()` yields |
| --- | --- |
| `q.code` | `Code` |
| `q.hcode` | `HierarchicalCode` |
| `q.dataflow` | `Dataflow` |
| `q.codelist` | **`LazyCodelist`**, not `Codelist` |
| `q.reported_attribute` | `MetadataSection` |

That fourth row is worth noting on its own: it is the same
declared-vs-returned divergence #370 dealt with on `LocalRegistry.get`, and
any typing here has to state which one it means.

## The partition is static

Only four tables have a resolver registered (`local/registry.py:2253`):
`artefact`, `code`, `hierarchy_node`, `metadata_value`. Measured across all 37
accessor roots on an empty `LocalRegistry`:

- **21 roots** where `collect()` builds objects — `agency_scheme`, `artefact`,
  `category_scheme`, `code`, `codelist`, `concept_scheme`, `data_constraint`,
  `data_provider_scheme`, `dataflow`, `dsd`, `hcode`, `hierarchy`,
  `hierarchy_association`, `metadata_provider_scheme`,
  `metadata_provision_agreement`, `metadata_set`, `metadataflow`, `msd`,
  `provision_agreement`, `reported_attribute`, `representation_map`
- **16 roots** where it raises `TypeError` — `agency`, `annotation`,
  `categorisation`, `category`, `component`, `concept`, `contact`,
  `cube_region`, `data_provider`, `group`, `hierarchy_applicability`,
  `key_value`, `metadata_attribute`, `metadata_provider`, `metadata_target`,
  `value_map`

That split is fixed per root, not per query — so it is knowable at type-check
time. Today it is a runtime `TypeError` with a good message
(`"collect() builds domain objects, and nothing knows how to build one from a
q.component row"`), but it is a runtime one.

## Blast radius

573 `.collect()` call sites (50 `src/`, 370 `tests/`, 153 `docs/`) and 34
`.first()` / `.one()` / `.one_or_none()`. Almost none of them are checked
today, because `tests/unit` is outside basedpyright (#347) and test bodies
that do reach it work on `object` without complaint until someone dots into
it.

## Options

1. **Parameterise the row kind by its artefact** — `class CodeRow(RowKind[Code])`,
   `class ComponentRow(RowKind[Never])`, and `collect() -> list[A]`. Fits the
   existing design: `RowKind` is already a phantom that exists purely so the
   checker can catch a mismatch, and this is the same trick for a second
   question. Bonus — the 16 refusing roots become *type* errors rather than
   runtime ones, which is strictly better than a good message. Cost: touching
   33 `RowKind` subclasses in `accessors.py`, and deciding `LazyCodelist`
   vs `Codelist` for the lazy roots.
2. **Overload `collect()`** on the `self` type per root. No change to the
   accessors, but 21 overloads that have to be kept in step with `_RESOLVERS`
   by hand — the thing option 1 makes structural.
3. **Leave it and document.** `collect()` is the expensive terminal and most
   call sites immediately iterate; `object` costs an `isinstance` at the few
   that dot in. Cheapest, and honest about the fact that `get_artefact`
   dispatches on a runtime column (CLAUDE.md already grants that one a
   scoped `ANN401`).

(1) is where the value is, and it is the only option that also makes the
16-root refusal static. Worth deciding before #347's `tests/unit` pass: 726 of
that pass's 1,111 findings are `reportArgumentType`/attribute-access, and some
number of them are this.

## Single artefact-kind registry

Today there are **four parallel dispatch tables** maintained by hand:
- \`src/sdmxlib/storage/writers.py:43\` — \`_CLASS_TO_NAME\`
- \`src/sdmxlib/storage/writers.py:1439\` — \`_WRITER_DISPATCH\`
- \`src/sdmxlib/storage/readers.py:1388\` — \`_READER_DISPATCH\`
- \`src/sdmxlib/storage/readers.py:69\` — \`_TYPE_REGISTRY\`

Plus the same \`if msg.X: container = ...; for x in msg.X: _write_X(container, x)\` chain repeated 12× in **three** writer files (\`sdmx_ml30/writer.py:737\`, \`sdmx_ml21/writer.py:628\`, \`sdmx_json/writer.py:735\`) — 36 copies of the same scaffolding.

- [ ] Define one \`ARTEFACT_KINDS: list[ArtefactKind]\` registry with \`(cls, name, writer, reader)\`; derive all four dispatch dicts.
- [ ] Replace the 36-copy writer scaffolding with a table-driven loop in each of the three format writers.

## De-underscore local/

\`src/sdmxlib/local/_data_store.py\` exports \`DuckDBDataStore\` which is publicly re-exported from \`sdmxlib.__init__\`. \`local/_registry.py\` exports \`Registry\` likewise. The underscore prefix lies.

- [ ] Rename \`local/_data_store.py\` → \`local/data_store.py\`.
- [ ] Rename \`local/_registry.py\` → \`local/registry.py\`.
- [ ] Re-export from \`local/__init__.py\` so top-level imports come from a public path.
- [ ] Update internal imports.

## RestRegistry.data simplification

\`src/sdmxlib/api/registry.py:519 RestRegistry.data\` is ~140 lines (C901, PLR0912). Branches twice on \`isinstance(dataflow, type)\` and defines four near-identical inner closures (\`_fetcher\` / \`_streamer\` × two arms).

- [ ] Extract a small \`_DataflowSpec\` record (\`agency, id, version, structure, dataflow\`); resolve it once.
- [ ] Replace the four inner closures with one fetcher pair sharing the spec.
- [ ] Drop \`_fetch_data_to\` by adding \`to: Path | None\` to \`_fetch_data\`.

Every `type: ignore` in `src/` (46 of them) carries a **mypy** error code — `arg-type`, `return-value`, `override`, `attr-defined`, `assignment`. **No mypy runs in this project.** For basedpyright and pyrefly, `# type: ignore[anything]` is a *blanket line suppression*; the bracket is decorative.

## Proof

```python
n: int = "not an int"   # type: ignore[arg-type]           → suppressed (wrong code)
m: int = "not an int"   # type: ignore[not-a-real-code]    → suppressed (invented code)
k: int = "nope"         # pyright: ignore[reportUnusedVariable] → NOT suppressed ✓
```

Only the `pyright:` form is rule-scoped.

## Why it matters

`CLAUDE.md` currently says:

> *"never a bare `# type: ignore` — always `# type: ignore[code]` so a different error at that line still surfaces"*

That rationale is **false for the toolchain in use** — the codes buy nothing. The cost is real: `api/client.py:70` carries one `# type: ignore[arg-type]` that is silencing **17 distinct errors** (see the sibling issue for that specific site).

There is a second reason to move, already recorded in `CLAUDE.md` from !184: both checkers honour `# type: ignore`, so a shared comment is *unattributable* — neither tool can tell whether it is dead or is carrying the other one's error. That is why pyrefly's `unused-type-ignore` has to stay off. Per-checker syntax fixes both problems at once.

## Fix

Convert each site to the syntax of the checker that actually needs it, with the real rule name:

* basedpyright → `# pyright: ignore[reportArgumentType]` etc.
* pyrefly → `# pyrefly: ignore[bad-argument-type]` etc.
* where **both** need it, both comments.

Determine "who needs it" mechanically: strip, run each checker separately, record which one complains.

Then correct the `CLAUDE.md` "Hygiene" bullet.

## Acceptance

* No `# type: ignore` left in `src/` (tests are a separate question).
* Each remaining suppression names a real rule of a checker that genuinely reports it there.
* Consider re-enabling pyrefly `unused-type-ignore` afterwards — it becomes meaningful once the shared form is gone.
* `just check` clean.

46 sites, mechanical but wide. Deserves its own MR; do it **after** the [S1] issues, which delete 24 of these outright.

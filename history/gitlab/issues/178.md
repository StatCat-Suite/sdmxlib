First step of the msgspec migration (milestone: SDMX-JSON dict+orjson → msgspec). Establishes the base every later issue builds on. **No behavior change** — orjson stays the primary engine; this only adds msgspec and the shared scaffolding.

## Scope
- Add `msgspec` to baseline runtime deps (500 KB, zero deps).
- Create the DTO module (e.g. `formats/sdmx_json/_dto.py`) holding the cross-cutting wire Structs: `Annotation`, `Link`, `Meta`/`Sender`/`Header`, and the shared `name`/`names` + `description`/`descriptions` convention.
- A shared `_istr(InternationalString) -> (primary: str|None, map: dict|None)` helper (write) and its inverse for ingest (read).
- Shared `msgspec.json.Encoder` / decoder instances.
- Codify the conventions the codelist spike surfaced:
  - `omit_defaults=True` for optional-when-absent fields.
  - **Fields that must always be emitted (`id`, `agencyID`, `version`) are REQUIRED (no default)** — otherwise `omit_defaults` silently drops them (the spike's `version`-disappeared bug).
  - `rename={"agency_id": "agencyID"}` (and any other camelCase wire names).
  - ignore-unknown-fields on decode (forward-compat).

## Test gates
- Roundtrip encode/decode for each shared Struct.
- A guard test asserting required fields (`id`/`agencyID`/`version`) are ALWAYS emitted even when equal to a plausible default — locks the omit_defaults discipline.
- Full suite green; orjson still in place.

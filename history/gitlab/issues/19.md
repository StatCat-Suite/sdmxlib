## Goal

Wire up `pytest-cov` (already installed) to produce a coverage report from all
tests, surface the percentage in CI, and add a badge to the README and docs that
links to the HTML report.

## Implementation

### 1. `pyproject.toml` — coverage config

Add `[tool.coverage.run]` and `[tool.coverage.report]` sections:

- `source = ["src/sdmxlib"]`
- Omit test files and anything not worth measuring
- Set a `fail_under` threshold once baseline is known

### 2. `justfile` — new recipe

```
# Run all tests with coverage report
coverage:
    uv run pytest -m "unit or docs" --cov --cov-report=term-missing --cov-report=xml --cov-report=html
```

### 3. `.gitlab-ci.yml` — coverage in CI

- Add a dedicated `coverage` job in the `quality` stage
- Pass `--cov --cov-report=term-missing --cov-report=xml` flags
- Add `coverage:` regex so GitLab extracts the percentage from job output:
  `'/TOTAL\s+\d+\s+\d+\s+(\d+)%/'`
- Publish the Cobertura XML as an artifact for inline MR diff annotation
- Publish the HTML report as a Pages artifact under `public/coverage/` so the
  badge links to a browsable report (reuse the existing `pages` job output path)

### 4. Badge

Add to `README.md` and `docs/index.md`:

```markdown
[![Coverage](https://gitlab.com/gabrielgellner/sdmxlib-v3/badges/main/coverage.svg)](https://gabrielgellner.gitlab.io/sdmxlib-v3/coverage/)
```

## Acceptance criteria

- [ ] `just coverage` runs all tests and prints a coverage summary + opens HTML report
- [ ] CI `coverage` job posts the percentage to the pipeline view
- [ ] MRs show inline per-file coverage diff (Cobertura artifact)
- [ ] Badge on `main` shows current percentage and links to HTML report
- [ ] `README.md` and `docs/index.md` both have the badge

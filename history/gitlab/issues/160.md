# Issue #160: Storage round-trip fidelity: Codelist extensions, DataConstraint reference_period/release_calendar, Level codingFormat

| | |
| --- | --- |

## Summary

Follow-up to the serializer round-trip audit (#159, closed). That work
closed 18 of 20 identified gaps; the two remaining are permanent
by-design wire-format limitations (SDMX-ML 2.1 `CodeMapType` has no
validity dates; SDMX 3.0 dropped `isFinal`) and stay as `xfail(strict)`
markers in the property guard.

This issue tracks the remaining **DuckDB storage** fidelity gaps — model
fields the storage writer receives but the schema has no column/table
for, so they are dropped on `put_artefact` → `get_artefact`. These were
deferred from #159 as lower blast-radius (not exercised by the property
guard yet).

## Gaps

1. **`Codelist.extensions`** (`tuple[CodelistExtension, ...]`) — SDMX
   3.0/3.1 codelist composition (inclusive/exclusive code selection,
   prefix). No table or columns; never written, never read. Needs a new
   table (e.g. `codelist_extension` + `code_selection` rows).

2. **`DataConstraint.reference_period`** and
   **`DataConstraint.release_calendar`** — model fields on
   `DataConstraint` (constraint.py). No columns on `data_constraint`;
   never written/read.

3. **`Level.coding_format`** (Facet) on hierarchy levels — `hierarchy_level`
   has only `name`/`description`. Dropped on storage round-trip. (The
   SDMX-ML 3.0 and SDMX-JSON writers persist this since #159; storage
   does not.)

## Acceptance

- Add the columns/table (bump `SCHEMA_VERSION`), wire writer + reader.
- Add a `put_hierarchy`-backed case to the round-trip property guard so
  `Level.coding_format` is exercised, and remove its `KNOWN_GAPS` entry
  once it round-trips (its strict xfail will confirm closure).
- Round-trip tests for each field.

## Context

The property guard (`tests/unit/test_roundtrip_property_guard.py`) is the
harness: add a `Check` per field; a fixed gap XPASSes (strict) → delete
its `KNOWN_GAPS` entry. See #159 for the full audit and the pattern used
across the merged batches.

**Tier 1 — safe, model-core.** From the `Any` audit (★4, GENERIC_ERASURE).

The URN-keyed stores are `dict[str, Any]`, so `Any` flows unchecked everywhere
they're touched. `object` is both honest ("some artefact") and sufficient — the
one unsafe narrowing already lives at the `get[T]` return (`# type: ignore`d).

**Sites**
- `model/in_memory_registry.py:52` `_store`, `:54` `_by_type: dict[type, list[Any]]`
- `api/session.py:40-43` (four `dict[str, Any]`)
- `local/registry.py:996` `_load_parent_scheme -> Any | None`, reflective walkers
  (`_walk_refs`/`_process_field`/`_intern_ref_field`, `_resolve_transitively`)

**Fix:** `dict[str, object]` / `list[object]` / `object | None`; keep the existing
`# type: ignore[return-value]` at each `get[T](SdmxUrn[T]) -> T | None` boundary.

**Note:** leave `_refs: dict[str, AnyRef]` for the covariant-`Ref` issue (T3) —
it narrows to `dict[str, Ref[object]]` there.

**Acceptance:** store bodies checked; `get[T]` still returns `T`; `just ci` green.
**Risk:** low.

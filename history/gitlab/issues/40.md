# Issue #40: HierarchicalCode missing Level reference (SDMX 3.1)

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-21 |
| Closed | 2026-04-22 |

## Summary

`sdmxlib/model/hierarchy.py` implements `HierarchicalCode` correctly for SDMX 3.0 but is missing the `Level` reference added in SDMX 3.1.

## Current state

```python
@define
class HierarchicalCode:
    id: str
    code: Ref[Code] | None
    name: InternationalString
    description: InternationalString
    children: ItemList[HierarchicalCode]
    annotations: Annotations
    valid_from: datetime | None
    valid_to: datetime | None
```

There is no corresponding `Level` artefact class and no `level` reference on `HierarchicalCode`.

## What changed in SDMX 3.1

SDMX 3.1 renamed "Code Association" to `HierarchicalCode` (already reflected here) and added a reference association from `HierarchicalCode` to a `Level` artefact.  `Level` allows each node in a `Hierarchy` to declare its structural level explicitly — rather than inferring level from code ID length or tree depth.

A `Level` artefact carries at minimum an `id` and `name`; a `Hierarchy` owns an ordered list of `Level` objects, and each `HierarchicalCode` node optionally references the `Level` it belongs to.

This matters for classifications with a formal level structure, e.g.:

| Level id | Level name         | NAICS code length |
|----------|--------------------|-------------------|
| `SECTOR` | Sector             | 2-digit           |
| `SUBSEC` | Subsector          | 3-digit           |
| `GROUP`  | Industry group     | 4-digit           |
| `IND`    | Industry           | 5-digit           |
| `CLASS`  | Industry class     | 6-digit           |

Without `Level`, consumers must infer level from tree depth or code ID patterns.

## Proposed change

Add a `Level` class to `hierarchy.py`:

```python
@define
class Level:
    id: str
    name: InternationalString = field(factory=InternationalString, converter=_to_istring)
    description: InternationalString = field(factory=InternationalString, converter=_to_istring)
    annotations: Annotations = field(factory=Annotations, converter=_to_annotations)
```

Add `levels` to `Hierarchy` and an optional `level` reference to `HierarchicalCode`:

```python
@define
class HierarchicalCode:
    ...
    level: Ref[Level] | None = None   # new in 3.1

@define
class Hierarchy(MaintainableArtefact):
    ...
    levels: ItemList[Level] = field(factory=ItemList)   # new in 3.1
    tree: ItemList[HierarchicalCode] = ...
```

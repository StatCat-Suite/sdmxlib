# Issue #18: feat(api): public API re-exports: to_xml, to_json, from_dict, to_dict, validate

| | |

| State | closed |

Wire up all new construction/validation/conversion functions into the public `sdmxlib` namespace and add `to_xml`/`to_json` entry points to `formats/__init__.py`.

## Motivation

Users should be able to do:

```python
import sdmxlib as sl

msg = sl.StructureMessage(codelists=[...], data_structures=[...])

# Validate
assert not sl.validate(dsd)
assert not sl.validate_references(msg)

# Serialize
xml_bytes  = sl.to_xml(msg, version="2.1")
json_bytes = sl.to_json(msg)

# Dict round-trip
d = sl.to_dict(dsd)
dsd2 = sl.from_dict(sl.DataStructure, d)
```

## Changes

**`formats/__init__.py`:**

Add `to_xml()` and `to_json()` as named entry points (alongside existing `serialize()`). Add `_wrap_in_message(artefact)` helper that accepts a single artefact (Codelist, DataStructure, etc.) and wraps it in a minimal `StructureMessage`.

```python
def to_xml(artefact: StructureMessage | Any, *, version: str = "2.1") -> bytes: ...
def to_json(artefact: StructureMessage | Any) -> bytes: ...
```

**`sdmxlib/__init__.py`:**

```python
from sdmxlib.model.convert import from_dict, to_dict
from sdmxlib.model.validation import (
    validate, validate_references,
    ValidationIssue, ReferenceIssue,
)
from sdmxlib.formats import to_xml, to_json
```

Add all eight names to `__all__`.

## Tests

- `sl.to_xml(msg)` produces parseable XML
- `sl.to_json(msg)` produces valid SDMX-JSON
- `sl.to_xml(codelist)` wraps single artefact correctly
- `sl.from_dict`, `sl.to_dict`, `sl.validate`, `sl.validate_references` accessible at top level

## Problem

The read-side guards are what milestone 20's confidence rests on:

- the element, attribute and JSON censuses;
- `test_read_losses`;
- the loss register;
- `formats/gaps.py`.

CLAUDE.md's rule is that a guard that has only ever passed is not known to be a guard. Each was watched to fail when written, but none has been checked for whether it would still fail after the code under it moves.

## Proposal

1. Run `just mutate-module` over the readers and writers (`formats/sdmx_ml*/`, `formats/sdmx_json/_structure_ingest.py`) and `formats/gaps.py`.
2. For each surviving mutant, either:
   - add or tighten a test that kills it; or
   - record why it is equivalent.
3. Report the kill rate per module, and the survivors that pointed to a real gap.

This is related to #324 (mutation testing) but scoped to the conformance surface, so it fits in minutes-to-hours runs.

## Done when

No unexplained survivors remain in the reader and writer modules.

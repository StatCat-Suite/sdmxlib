# Issue #509: write_sdmx_json_data defaults lang to "en"

| | |
| --- | --- |
| State | closed |
| Opened | 2026-10-20 |
| Closed | 2026-10-20 |
| Milestone | %26 Found by the docs audit: correctness and refusals |
| Labels | `api`, `breaking-change`, `bug`, `priority::medium` |

`write_sdmx_json_data` (`formats/sdmx_json/data_v1.py` and `data_v2.py`) has `lang: str = "en"`, a default language. The library rule is that every multilingual API takes `lang` with no default (no `"en"` fallback anywhere).

**Fix:** make `lang` required, and check `Dataset.sink_json` and `write_data_json`, which call it. This is a breaking change for callers that relied on the default.

# Issue #31: migrate domain model from dataclasses to attrs

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-03 |
| Closed | 2026-04-03 |

Replace `@dataclass(frozen=True, slots=True)` with `@define(frozen=True)` across `sdmxlib/model/`. Primary motivation: `field(converter=...)` eliminates the `ItemList[T] | list[T]` union anti-pattern on collection fields, giving precise `ItemList[T]` types everywhere.

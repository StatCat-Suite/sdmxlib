16 occurrences of `Ref[Any]`, alongside an existing `AnyRef` alias used in several signatures.

First question is cheap and decides the shape of the work: **is `AnyRef` the intended spelling for these?** If so most of this is a rename with no semantic change. If `AnyRef` means something narrower, the two need distinguishing in prose before either is used more widely.

Only after that: which of the remainder are genuinely recovering the type parameter (same bivariance argument as #t-5) and which are pure consumers that want `Ref[object]`.

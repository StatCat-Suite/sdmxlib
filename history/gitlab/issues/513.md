# Issue #513: AncestorMap.ancestors() returns a private type

| | |
| --- | --- |
| State | closed |
| Opened | 2026-10-20 |
| Closed | 2026-10-20 |
| Milestone | %26 Found by the docs audit: correctness and refusals |
| Labels | `api`, `priority::low` |

`sl.AncestorMap` is public, but `AncestorMap.ancestors()` returns the private `sdmxlib.model.rollup._AncestorTargets`. `test_public_surface` fails if `AncestorMap` is rendered in `docs/api.md`, so it is the one public class `api.md` leaves out.

**Fix:** either make the return type public (named, exported, documented), or return a public type such as a `Mapping`. Then add `AncestorMap` to `api.md`.

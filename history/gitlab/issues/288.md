39 occurrences, concentrated in `storage/writers.py`, `storage/readers.py` and the format layer — i.e. the boundary CLAUDE.md explicitly calls the legitimate home of `Any`:

> **Typed core, untyped shell.** The `Any` boundary is the format/storage layer (msgspec untyped decode, lxml, duckdb rows): parse → validate → hand typed domain objects inward.

So this is the category most likely to end in "some of these should stay". Do it **last**, and treat a written reason as an acceptable outcome for a site rather than a failure.

Where it *is* worth changing: a `list[Any]` that is only iterated and passed on wants `list[object]`; one whose element type is recoverable wants a generic. `readers.get_artefact` returning `Any` is already sanctioned with a documented `# noqa: ANN401` and is not in scope.

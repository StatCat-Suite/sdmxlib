# Issue #144: perf: type-dispatched _delete_artefact_cascade (epic #141 step 3)

Part of epic #141 — re-ingest-only optimization.

## Problem

After Step 2 (#143), fresh-bundle persists skip the cascade entirely. But **re-ingest** of an existing bundle (or a partial replacement — drop + add) still pays the full cost: ~35 DELETE statements per artefact, where ~30 are guaranteed no-ops because each artefact class only writes to a handful of tables.

A Codelist only ever has rows in `code` + `localized_text` + `annotation` + `annotation_text` + `artefact_ref`. The other 28 DELETEs (`hierarchy_node`, `dsd_component`, `metadata_value`, `cube_region`, `provision_agreement`, …) are dead.

## Proposed change

Replace the unconditional cascade with a type-dispatched one:

```python
_CASCADE_TABLES: dict[str, list[str]] = {
    "Codelist": ["code"],
    "Hierarchy": ["hierarchy_node", "hierarchy_level", "hierarchy_meta", "hierarchy_association"],
    "DataStructure": ["dsd_component", "dsd_group", "group_dimension"],
    "Dataflow": ["dataflow"],
    "ConceptScheme": ["concept"],
    "CategoryScheme": ["category", "categorisation"],
    "MetadataStructure": ["metadata_attribute", "metadata_structure"],
    "Metadataflow": ["metadataflow"],
    "MetadataSet": ["metadata_value", "metadata_target", "metadata_set"],
    "AgencyScheme": ["agency", "agency_contact", "data_provider"],
    "DataProviderScheme": ["data_provider"],
    "ProvisionAgreement": ["provision_agreement"],
    "DataConstraint": ["region_key_value", "cube_region", "data_constraint"],
    "RepresentationMap": ["value_map", "representation_map"],
    "DataflowBinding": ["dataflow_binding"],
    # ... etc.
}

def _delete_artefact_cascade(conn, urn, artefact_class):
    for table in _CASCADE_TABLES[artefact_class]:
        conn.execute(f"DELETE FROM {table} WHERE ... = ?", [urn])
    # Plus the universal tables every artefact uses:
    #   localized_text, annotation, annotation_text, artefact_ref
    # (Those still need their own DELETEs but for an artefact-class-specific subset.)
```

Each `put_*` already knows its own class, so callers pass it through with no plumbing on the model side.

## Expected impact

Re-ingest only: ~35 DELETEs → ~3-5 per artefact. **5-7× on re-ingest cascade cost**, complementary to Step 2 (which is fresh-write-only).

## Acceptance

- `_delete_artefact_cascade(conn, urn, artefact_class)` runs only the relevant DELETEs for that class.
- All existing round-trip tests still pass — particularly re-ingest tests (`test_add_overwrites_existing`, etc.).
- Add a unit test: count DELETE statements during a Codelist re-write and verify the count is ≤6 (not ~35).
- Bench shows a re-ingest improvement (add new bench param: ingest-then-ingest-again).

## Depends on

- #142 (instrumentation) so the re-ingest improvement is measurable.
- #143 (Step 2) lands first — that's the bigger common-case win.

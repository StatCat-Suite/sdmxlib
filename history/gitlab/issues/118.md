# Issue #118: perf: ItemList.__getitem__ dispatch overhead (2-3× vs raw dict)

| | |
| --- | --- |

## Context

Surfaced by Phase 3 bench (MR !81). \`test_nav_dim_lookup\` measures 68 ns per \`dsd.dimensions[\"D00\"]\` lookup vs 31 ns for an equivalent \`dim_by_id[\"D00\"]\` on a pre-built dict — a **2.2× overhead**.

\`ItemList\` *already* maintains a \`_by_id: dict[str, T]\` index (\`src/sdmxlib/model/collections.py:80\`), so the lookup itself is O(1). The tax is the dispatch in \`__getitem__\`:

\`\`\`python
def __getitem__(self, index: int | str | slice) -> T | ItemList[T]:
    if isinstance(index, int):
        return self._items[index]
    if isinstance(index, slice):
        return ItemList(list(self._items[index]))
    try:
        return self._by_id[index]
    except KeyError:
        msg = f\"No item with id {index!r}\"
        raise KeyError(msg) from None
\`\`\`

Per call: two \`isinstance\` checks + a try/except frame before the actual dict hit. At 35-40 ns of overhead per call, it shows up everywhere the model is walked (full \`dsd.code_map\` traversal of a 10×200 DSD pays the tax 200+ times).

## Why this matters

Phase 3 walk-all-codes bench: **17.9 µs (nav) vs 3.1 µs (direct dict)** on the 10×200 DSD — 5.8× tax. Most of the difference is \`__getitem__\` overhead × iterations, not \`Ref\` resolution.

## Proposed fix

Two cheap options:

1. **Reorder the type-dispatch** so string lookup (the common case) hits first. \`isinstance(index, str)\` then dict lookup; falls through to int/slice handling. Cuts one isinstance per common-case call.
2. **Add a fast-path method**: \`get_by_id(id: str) -> T\` that skips dispatch entirely. Used internally by hot model paths (e.g., \`Component.codelist\`, \`dsd.code_map\`); user-facing \`dims[\"FREQ\"]\` continues to dispatch.

(1) is one-line and zero-API-change. (2) compounds harder but only matters for internal hot paths.

## Estimated impact

- Per-call: drop nav dim lookup from 68 ns → ~45 ns (2.2× → ~1.5× tax).
- \`code_map\` over 10×200 DSD: shave a few µs off the 17.9 µs total — proportional to ItemList walks involved.

## Acceptance

- \`just bench\` shows \`test_nav_dim_lookup\` measurably faster; \`test_direct_dim_lookup\` unchanged.
- \`test_nav_walk_all_codes\` tax drops.
- Existing \`tests/unit/test_collections.py\` still green; dispatch semantics preserved.

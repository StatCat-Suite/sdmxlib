Milestone: SDMX-JSON dict+orjson → msgspec. Replace the dict-building structure writer with typed `msgspec.Struct` DTOs + `Encoder.encode`. This is the largest surface (every structure artefact type) but the approach is spike-proven (~25% faster serialize).

## Scope
Define wire-shape DTO Structs for **every** structure artefact and replace `writer.py` + `structure_values.py` dict assembly with attrs → Struct → encode:
- Codelist / Code, ConceptScheme / Concept, DataStructure (DSD) + Dimension/Attribute/Measure/Group, Dataflow, CategoryScheme / Category, Categorisation, Hierarchy / HierarchicalCode, MetadataStructure (MSD) / MetadataAttribute, Metadataflow, ProvisionAgreement, AgencyScheme, DataProviderScheme, StructureMap / ConceptSchemeMap / CategorySchemeMap / RepresentationMap, DataConstraint.

If the diff is unwieldy, split by artefact family into sub-MRs (items → structures → maps/constraints) landing behind the same `serialize(version=\"json\")` seam.

## Test gates
- **Output parity**: semantically-identical JSON vs the current writer for every artefact type (fixture-based key/value comparison).
- Existing SDMX-JSON writer roundtrip tests pass.
- JSON-schema validation of emitted output (against the vendored SDMX-JSON structure schema).
- Enforce the required-fields discipline from #178 (no dropped `version`/`id`/`agencyID`).

**Depends on:** #178 (Foundation — shared Structs, conventions). **Pairs with:** #181 (read side reuses these DTOs).

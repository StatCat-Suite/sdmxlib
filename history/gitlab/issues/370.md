# Issue #370: LocalRegistry.get accepts a str its signature denies, and disagrees with RestRegistry.get

| | |
| --- | --- |
| State | closed |
| Opened | 2026-08-22 |
| Closed | 2026-09-07 |

Found by type-checking `tests/` for #347.

## The inconsistency

```python
def get(self, urn: SdmxUrn[T], *, eager: bool = False) -> T | None: ...
```

but a plain `str` works:

```python
reg.add(cl)
reg.get(str(cl.urn))   # -> Codelist. No error, no warning.
```

**20 test call sites depend on it** — `local.get(urn)` where `urn` came back from a helper as a string. The docstring never mentions `str`.

Meanwhile the sibling entry point declares a *different* union:

| | declared |
| --- | --- |
| `LocalRegistry.get` | `SdmxUrn[T]` |
| `RestRegistry.get` | `SdmxUrn[T] \| Ref[T]` |

So neither accepts `str` on paper, one accepts it in fact, and they do not agree with each other about `Ref` either.

## Why it matters

This is the shape that makes a test pass for the wrong reason: the call is checked against a signature nobody runs (`tests/` is unchecked), so the mismatch is invisible in both directions — the implementation is looser than the type, and the callers are looser than the implementation.

It also interacts with #338's finding. A bare string is *not* an artefact identity: that was the argument for removing the `latest`-keyed caches, since a pointer served from a cache that never re-asks where it points is wrong for the life of the process. Accepting `str` here quietly widens what can be used as a key.

## Options

1. **Widen the signature** to `SdmxUrn[T] | str`, documenting what already happens. The 20 call sites become correct rather than tolerated. Cheapest, and blesses the looser API.
2. **Reject `str`** with a runtime guard and fix the call sites to build a real `SdmxUrn`. Tightest, consistent with `RestRegistry`, and breaking for anyone relying on the undeclared behaviour.
3. **Align the two `get`s** as a single decision — whatever the answer, `LocalRegistry.get` and `RestRegistry.get` should accept the same things, and today they do not.

(3) is the part worth deciding first: the `str` question is downstream of whether the two entry points are meant to have the same contract.

Not urgent — nothing is broken at runtime. It is a signature that lies, in a direction that has so far been convenient.

# Issue #41: sdmx data format

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-26 |

As I use parquet more, wondering if it makes sense to have some kind of dataformat like .sdf (sdmx data format) that would have the data in parquet and some kind of metadata catalog (json?) in an archive, so that you could have readers that would just open it and be able to do all the basic dataframe like operations on the parquet, but also have access to all the structural metadata etc for labels and so on. I know some formats (the office formats etc) have done this kind of bundingling with a zip, but is their some other cross platform format that could be used to group the files without having to much overhead when unpacking/reading?

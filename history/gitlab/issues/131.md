# Issue #131: model: RepresentationMap source/target as dataType (not just artefact Ref)

## Context

Surfaced by the SDMX-JSON 2.1 schema-variant audit (MR !98).

\`RepresentationMapType.source\` (and \`target\`) per the spec is an array of reference objects with a oneOf over two variants:

- \`{codelist: <urn>}\` — references a codelist (the current behaviour)
- \`{dataType: <SimpleDataType>}\` — source/target is a primitive datatype (e.g. ``String``, ``Integer``, ``Decimal``)

The \`dataType\` variant supports representation maps that translate between coded and free-text representations — e.g. mapping codelist codes to integer values, or converting between two text formats with different patterns.

Our model's \`RepresentationMap\` (src/sdmxlib/model/mapping.py) has source/target as ``AnyRef | None`` — always an artefact reference, never a primitive type. The \`dataType\` variant is unreachable from sdmxlib state.

## Why this matters

Real cross-mapping scenarios sometimes need to translate between coded and uncoded representations. We currently can't model or emit those.

## Proposed shape

Two options:

**A. Discriminated union via a small wrapper type.**

\`\`\`python
@frozen
class CodelistMapSource:
    codelist: Ref[Codelist]

@frozen
class DataTypeMapSource:
    data_type: str  # e.g. "String", "Integer"

MapEndpoint = CodelistMapSource | DataTypeMapSource

@define
class RepresentationMap(MaintainableArtefact):
    ...
    source: MapEndpoint | None = None
    target: MapEndpoint | None = None
\`\`\`

**B. Add an alternate \`source_data_type\` / \`target_data_type\` field alongside the existing source/target.**

(A) is cleaner — single field, type-safe variant. Writers/readers across formats then pattern-match on the variant.

## Acceptance

- Source/target can carry either a codelist Ref or a data-type literal.
- Round-trips through XML 3.0/3.1 (\`<str:Source><str:DataType>String</str:DataType></str:Source>\`) and JSON 2.1 (\`source: [{dataType: \"String\"}]\`).
- The audit's \`RepresentationMap.source: dataType\` gap closes — exercised by at least one fixture.

# Issue #462: SDMX-JSON structure write is 3.4x slower since M20: per-code URNs, links and wildcard checks

| Labels | `perf`, `sdmx-json` |

## Measured

Writing BIS codelists as SDMX-JSON went from **4.3 ms to 14.5 ms (+236%)** across milestone 20. pysdmx writes the same codelists in 5 ms. The DSD JSON write went from 0.5 ms to 1.0 ms.

## Leads (profiler; confirm by A/B)

The work for each code dominates:
- `SdmxUrn.make` (56,700 calls over 5 writes), `base.urn` and `SdmxUrn.__str__`: a URN is built for every code to fill links;
- `uri_links` and `link_to` (#422, links);
- `emit_annotations`;
- `Codelist.wildcard_misfits` (#451), once per codelist (105 per write) costing 0.083 s cumulative over 5 writes, which runs even when a codelist has no extensions.

## Direction

Skip per-code work when it can't apply, for example:
- no links, so no URN;
- no extensions, so no wildcard check.

Guard the fix with call counts.

## Done when

The JSON write is back near its pre-M20 time, the output is unchanged (the round-trip and schema-validity tests are green), and a count guard is in place.

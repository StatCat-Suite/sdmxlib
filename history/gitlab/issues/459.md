## Problem

The censuses cover **structure** messages. Data messages and reference-metadata messages have their own schemas:

- generic and structure-specific data;
- `GenericMetadata` / the SDMX-JSON metadata schema;
- SDMX-CSV.

It is unmeasured how far those are guarded the same way: whether every element is owned, losses are reported, and readers are closed-world.

## Proposal

1. Measure first: for each message type and version, list which of these guards exist:
   - XSD validation of output;
   - a census;
   - a loss register;
   - closed-world reading;
   - cross-format round trip.
2. File the gaps found as their own issues in this milestone, with the measurement attached.

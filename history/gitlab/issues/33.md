# Issue #33: to_dict crashes on Attribute.related_dimensions (list[str])

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-11 |
| Closed | 2026-04-11 |

## Bug

`to_dict()` raises `NotAnAttrsClassError` when serializing a `DataStructure` that has `Attribute` objects with `related_dimensions` set (a `list[str]`).

The `_value_to_dict` helper in `model/convert.py` recurses into lists and calls `to_dict()` on each element. When the list contains plain strings (not attrs objects), `attrs.fields(type(artefact))` raises `NotAnAttrsClassError`.

## Reproduce

```python
import sdmxlib as sl
from sdmxlib.local import LocalRegistry

dsd = sl.DataStructure(
    id="DSD_TEST", maintainer="STC", version="1.0",
    name={"en": "Test"},
    dimensions=[sl.Dimension(id="DIM1",
        representation=sl.Codelist.urn(agency="STC", id="CL_GEO", version="1.0"))],
    time_dimension=sl.TimeDimension(),
    measures=[sl.Measure(id="OBS_VALUE")],
    attributes=[
        sl.Attribute(
            id="UNIT_MEASURE",
            attachment=sl.AttachmentLevel.SERIES,
            related_dimensions=["DIM1"],
            representation=sl.Facet(type="String"),
        )
    ],
)

local = LocalRegistry(":memory:")
local.add(dsd)  # crashes here
```

## Traceback

```
attrs.exceptions.NotAnAttrsClassError: <class 'str'> is not an attrs-decorated class.
```

The call chain is: `LocalRegistry.add()` → `_add_blob()` → `to_dict(artefact)` → `_value_to_dict("attributes", [...])` → `to_dict(Attribute)` → `_value_to_dict("related_dimensions", ["DIM1"])` → `to_dict("DIM1")` → `attrs.fields(str)` 💥

## Expected

`_value_to_dict` should handle lists of primitives (str, int, etc.) by returning them as-is rather than recursing into `to_dict()`.

## Workaround

Strip attributes before storing: `attrs.evolve(dsd, attributes=[])`. This works when DSD attributes aren't needed at runtime.

## Version

sdmxlib 0.7.0

# Issue #34: Shared DuckDB storage layer (sdmxlib.storage)

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-12 |
| Closed | 2026-04-12 |

Implement the shared storage layer spec from `docs/design/SHARED_STORAGE_SPEC.md`.

Refactors `LocalRegistry` from SQLite to DuckDB and extracts a public `sdmxlib.storage` module with normalized tables for codelists, DSDs, dataflows, and concept schemes. Enables future sharing with cataloglib via a common DuckDB connection.

## Scope (sdmxlib only — steps 1–4 of spec)

1. `sdmxlib.storage.schema` — DDL, `create_tables()`
2. `sdmxlib.storage.writers` — `put_codelist`, `put_data_structure`, `put_dataflow`, `put_artefact`, `ingest_registry`
3. `sdmxlib.storage.readers` — `get_codelist`, `get_data_structure`, `get_dataflow`, `get_artefact`, `code_map`, `code_map_for_dsd`
4. Refactor `LocalRegistry` to use `sdmxlib.storage` internally; accept `DuckDBPyConnection` in constructor
5. All existing `LocalRegistry` tests pass unchanged

See `docs/design/SHARED_STORAGE_SPEC.md` for full spec.

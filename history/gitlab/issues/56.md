### 2026-05-02

Closed in v0.18.0 (commit 3fe4602). Per the refinement comment, KeyFilter is replaced by ComponentFilter which carries both dimension and attribute filters. parse_components(key, component_filters, key_dimension_ids) accepts the SDMX REST 2.0 c[…]=… query params alongside the dotted key — components matching a key dim overlay onto dimensions, the rest land on attributes and translate via binding.attribute_column_map at query time. DataStore / FederatedCatalog query/query_stream accept component_filter=. New cookbook page docs/cookbook/rest_facade.md covers the full kit. BREAKING vs v0.17: KeyFilter/parse_key removed, key_filter param renamed to component_filter — pre-stability, no compat shim.

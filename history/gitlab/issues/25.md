# Issue #25: Accept bare SdmxUrn on codelist/concept fields

| | |
| --- | --- |
| State | closed |
| Opened | 2026-04-01 |
| Closed | 2026-04-01 |

Currently users must wrap SdmxUrn in Ref.unresolved() when constructing Dimension/Attribute/Measure:\n\n```python\nsl.Dimension(\n    id="FREQ",\n    codelist=sl.Ref.unresolved(sl.Codelist.urn(agency="SDMX", id="CL_FREQ", version="1.0")),\n    concept=sl.Ref.unresolved(sl.Concept.urn(agency="SDMX", scheme="CROSS_DOMAIN_CONCEPTS", id="FREQ")),\n)\n```\n\nWith this improvement, bare SdmxUrn is accepted directly:\n\n```python\nsl.Dimension(\n    id="FREQ",\n    codelist=sl.Codelist.urn(agency="SDMX", id="CL_FREQ", version="1.0"),\n    concept=sl.Concept.urn(agency="SDMX", scheme="CROSS_DOMAIN_CONCEPTS", id="FREQ"),\n)\n```\n\nThe __post_init__ coercion already handles Codelist -> Ref; extend it to handle SdmxUrn -> Ref.unresolved(urn).\n\nSame for Attribute, Measure, and Dataflow.structure field.

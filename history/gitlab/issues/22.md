## Context

Change 3 from `docs/design/round_trip_fidelity.md`.

StructureSets contain `CodelistMap` entries — code-level mappings from one codelist to another (e.g. CL_CURRENCY → CL_AREA_EE). These are present in `test_registry_codelist.yaml` and `test_registry_resolve_urn.yaml` cassettes but are currently silently dropped on parse.

## Changes needed

**New file `model/mapping.py`**:
- `CodeMap(source_id, target_id)` — single code mapping
- `CodelistMap(id, name, source, target, maps)` — with `translate(code) -> str | None`
- `StructureSet(MaintainableArtefact)` with `_sdmx_package="mapping"`, `_sdmx_class="StructureSet"`, `codelist_maps: tuple[CodelistMap, ...]`

**`model/message.py`**: Add `structure_sets: ArtefactList[StructureSet]`

**`model/__init__.py`** + **`sdmxlib/__init__.py`**: Export new types

**SDMX-ML 2.1 reader**: `_read_structure_sets()` in Phase 4

**SDMX-ML 2.1 writer**: `_write_structure_sets()` block

**SDMX-ML 3.0 reader + writer**: Same (identical XML shape)

**SDMX-JSON reader + writer**: Under `structureSets` key

**Fixtures**: Add `StructureSet` to `minimal.xml` (2.1 + 3.0)

**Tests**: Round-trip assertions + `translate()` correctness

After this lands, Change 4 (complete.xml fixtures + acceptance test) follows.

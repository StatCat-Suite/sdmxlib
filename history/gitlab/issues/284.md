## The gap

CLAUDE.md: "`src/` now carries **zero** `Any`-annotated parameters or locals, and an `Any` parameter anywhere is a finding." `ANN401` enforces that for bare annotations.

It does not look inside generic arguments:

```python
def f(x: Any) -> None: ...              # ANN401 finding
def f(x: dict[str, Any]) -> None: ...   # silent
```

The audit found **112 of 171** `Any` occurrences are the second form. So the rule as enforced covers about 4 of 171 sites, and the documentation overstates what is guaranteed.

## Why a ratchet rather than a rule

No linter in the stack has a rule for this, and writing one is out of proportion. But the repo already has the right technique for "cannot fix it all now, must not grow": the pyrefly deny-list, where every entry carries the measured count that justifies it.

Add a check to `just check` that counts `Any` in `src/` and fails above a committed baseline. ~15 lines. It converts an intention into something that cannot quietly reverse, and each subsequent issue in this milestone lowers the number.

## Design notes

- Count occurrences, not files — the number must move when one site is fixed.
- Exclude comments and docstrings, or the count is noise (18 of the current 171).
- Store the baseline in a committed file next to the script, so lowering it is a visible diff.
- Emit the per-category breakdown on failure, so a regression says *which* shape grew.

## Acceptance

- Baseline committed at the post-#t-1 count.
- Adding a `dict[str, Any]` to `src/` fails `just check`.
- `CLAUDE.md` corrected: it currently claims more than `ANN401` delivers.

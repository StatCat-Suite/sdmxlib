# History

Records of how sdmxlib got here, kept as written. Living text (code, the
`EGM.md` contracts, `docs/`, `CLAUDE.md`) states what the code does now and
cites these where a reader needs the reason.

- [`gitlab/`](gitlab/README.md): the GitLab tracker, exported. A bare `#N`,
  `!N` or `%N` anywhere in the tree is an issue, merge request or milestone
  there.
- [`design-archive/`](design-archive/README.md): the specs written before the
  code, superseded by it and by `docs/design/`.

A design document in `docs/design/` that the code no longer follows moves
here, under `design/`, headed with a line naming what replaced it
([GH-267](https://github.com/StatCat-Suite/sdmxlib/issues/267)).

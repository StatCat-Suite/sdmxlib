# src

## Overview

`src/` holds the `sdmxlib` package, laid out as a src-layout distribution and
built from `pyproject.toml`. It contains no source files of its own.

## Subdirectories & Boundaries

- sdmxlib: [`./sdmxlib/EGM.md`](./sdmxlib/EGM.md). The SDMX library: the frozen
  attrs model, wire formats, the DuckDB store and editions, the path query
  language, and the REST registries.
